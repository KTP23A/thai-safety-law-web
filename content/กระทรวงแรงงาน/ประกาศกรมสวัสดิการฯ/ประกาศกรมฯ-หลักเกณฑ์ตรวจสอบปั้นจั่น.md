# ประกาศกรมฯ เรื่อง หลักเกณฑ์การตรวจสอบส่วนประกอบและอุปกรณ์ปั้นจั่น

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์ วิธีการ และความถี่ในการ **ตรวจสอบส่วนประกอบและอุปกรณ์ของปั้นจั่น** เพื่อให้มั่นใจว่าปั้นจั่นมีสภาพพร้อมใช้งานอย่างปลอดภัยตลอดเวลา

## ความถี่การตรวจสอบ
| ประเภทการตรวจ | ความถี่ | ผู้ตรวจ |
|-------------|---------|--------|
| การตรวจก่อนใช้งาน (Pre-operation check) | ทุกวัน | ผู้บังคับปั้นจั่น |
| การตรวจประจำสัปดาห์ (Weekly inspection) | ทุกสัปดาห์ | ผู้บังคับปั้นจั่น |
| การตรวจประจำเดือน (Monthly inspection) | ทุกเดือน | ช่างผู้ชำนาญ |
| การตรวจประจำปี (Annual inspection) | ปีละ 1 ครั้ง | วิศวกรเครื่องกล |
| การทดสอบรับน้ำหนัก (Load test) | ทุก 5 ปี หรือหลังซ่อมใหญ่ | วิศวกรเครื่องกล |

## รายการตรวจสอบหลัก
| ส่วนประกอบ | รายการตรวจ |
|-----------|-----------|
| โครงสร้างเหล็ก | รอยแตก การกัดกร่อน การเสียรูป |
| ระบบไฟฟ้า | ฉนวน สายไฟ สวิตช์ป้องกัน |
| ระบบเบรก | ประสิทธิภาพการหยุด |
| ขอเกี่ยว (Hook) | รอยแตก การล็อก Safety latch |
| ลวดสลิง | รอยกระดก สึกหรอ เส้นขาด |
| ลูกล้อและรอก | การหมุน ความสึกหรอ |
| ระบบจำกัดการทำงาน (Limit switch) | การทำงานที่ถูกต้อง |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] บันทึกผลการตรวจสอบลง **สมุดบันทึกประจำเครื่อง** ทุกครั้ง
- [ ] หยุดใช้ปั้นจั่นทันทีเมื่อพบข้อบกพร่อง **ก่อนซ่อมแซม**
- [ ] แต่งตั้ง **ผู้รับผิดชอบ** ในการตรวจสอบอย่างเป็นทางการ
- [ ] ส่งผลการตรวจสอบประจำปีแก่ **พนักงานตรวจความปลอดภัย**
