# ประกาศกรมฯ เรื่อง หลักเกณฑ์อบรมผู้ปฏิบัติงานที่อับอากาศ

## สรุปสาระสำคัญ
กำหนดหลักสูตร จำนวนชั่วโมง คุณสมบัติวิทยากร และการออกวุฒิบัตรสำหรับการฝึกอบรมผู้ที่เกี่ยวข้องกับงานในที่อับอากาศ แบ่งเป็น 3 หลักสูตรตามบทบาท

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] **ผู้อนุญาต (Permit Issuer):** อบรม **18 ชั่วโมง** + ทดสอบ
- [ ] **ผู้ควบคุม (Supervisor):** อบรม **12 ชั่วโมง** + ทดสอบ
- [ ] **ผู้ปฏิบัติงาน (Worker) และ ผู้เฝ้าระวัง (Standby):** อบรม **6 ชั่วโมง** + ทดสอบ
- [ ] ต้องอบรมซ้ำทุก **3 ปี** หรือเมื่อเปลี่ยนบทบาท
- [ ] วิทยากรต้องมีประสบการณ์งานที่อับอากาศ **ไม่น้อยกว่า 3 ปี**
- [ ] สถานที่อบรมต้องได้รับการรับรองจาก **กรมสวัสดิการฯ**
- [ ] เก็บบันทึกการอบรมไว้ **ไม่น้อยกว่า 5 ปี**

## ผู้ที่เกี่ยวข้อง
- **นายจ้าง:** จัดส่งลูกจ้างเข้ารับการอบรมตามบทบาท
- **ลูกจ้าง:** ผ่านอบรมและทดสอบตามหลักสูตรที่กำหนด
- **หน่วยฝึกอบรม:** ต้องได้รับการรับรองจากกรมสวัสดิการฯ

## บทลงโทษ
ฝ่าฝืน: ปรับไม่เกิน 50,000 บาท (ตาม [[กฎกระทรวง-ที่อับอากาศ-2562]] และ [[พ.ร.บ.ความปลอดภัยอาชีวอนามัยฯ-2554]])
