# ประกาศกรมฯ เรื่อง หลักเกณฑ์การจัดทำ SDS และบัญชีรายชื่อสารเคมีอันตราย

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์ วิธีการ และรูปแบบในการจัดทำ **เอกสารข้อมูลความปลอดภัย (Safety Data Sheet — SDS)** และ **บัญชีรายชื่อสารเคมีอันตราย** สำหรับสถานประกอบการที่มีการใช้ นำเข้า ผลิต หรือจัดเก็บสารเคมีอันตราย

## โครงสร้าง SDS (16 หัวข้อตาม GHS)
| ข้อ | หัวข้อ |
|-----|--------|
| 1 | ชื่อสาร/สารผสม และชื่อบริษัท |
| 2 | การระบุความเป็นอันตราย (GHS Classification) |
| 3 | ส่วนประกอบ/ข้อมูลเกี่ยวกับส่วนผสม |
| 4 | มาตรการปฐมพยาบาล |
| 5 | มาตรการด้านการดับเพลิง |
| 6 | มาตรการจัดการเมื่อมีการหกรั่วไหล |
| 7 | การขนถ่ายและการเก็บรักษา |
| 8 | การควบคุมการสัมผัส/การป้องกันส่วนบุคคล |
| 9 | คุณสมบัติทางกายภาพและเคมี |
| 10 | ความเสถียรและการเกิดปฏิกิริยา |
| 11 | ข้อมูลด้านพิษวิทยา |
| 12 | ข้อมูลด้านนิเวศวิทยา |
| 13 | ข้อพิจารณาด้านการกำจัด |
| 14 | ข้อมูลการขนส่ง |
| 15 | ข้อมูลกฎข้อบังคับ |
| 16 | ข้อมูลอื่น ๆ |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำ SDS **ภาษาไทย** สำหรับสารเคมีอันตรายทุกชนิดที่ใช้ในสถานประกอบการ
- [ ] ติด **ฉลาก GHS** บนภาชนะบรรจุสารเคมีทุกชนิด
- [ ] จัดให้ SDS **เข้าถึงได้ง่าย** สำหรับลูกจ้างที่ทำงานกับสารเคมี
- [ ] **อัปเดต SDS** เมื่อมีข้อมูลใหม่หรือการเปลี่ยนแปลงองค์ประกอบ
- [ ] จัดทำ **บัญชีรายชื่อสารเคมี** ครบถ้วนและเป็นปัจจุบัน
- [ ] จัดอบรมลูกจ้างเรื่องการอ่าน SDS และฉลาก GHS
