# ประกาศกรมฯ เรื่อง มาตรฐานอุปกรณ์คุ้มครองความปลอดภัยส่วนบุคคล (PPE)

## สรุปสาระสำคัญ
กำหนด **มาตรฐานอุปกรณ์คุ้มครองความปลอดภัยส่วนบุคคล (Personal Protective Equipment — PPE)** ที่นายจ้างต้องจัดให้ลูกจ้างใช้ตามความเสี่ยงในการทำงาน รวมถึงมาตรฐานการผลิต การทดสอบ และการตรวจสอบ PPE

## ประเภท PPE และมาตรฐาน
| ประเภท | มาตรฐาน/ข้อกำหนด |
|--------|----------------|
| หมวกนิรภัย (Hard Hat) | มอก. หรือ ANSI Z89 |
| รองเท้านิรภัย (Safety Shoes) | มอก. หรือ EN ISO 20345 |
| แว่นตานิรภัย (Safety Glasses) | มอก. หรือ ANSI Z87 |
| ที่ครอบหู / ที่อุดหู (Ear Protection) | SNR ≥ ค่าที่กำหนด |
| หน้ากากกรองฝุ่น/ก๊าซ (Respirator) | มอก. หรือ NIOSH |
| สายรัดนิรภัย (Safety Harness) | มอก. หรือ EN 361 |
| ถุงมือนิรภัย (Safety Gloves) | ตามประเภทอันตราย |
| ชุดป้องกันสารเคมี | ตามระดับอันตราย A-D |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดหา PPE **ที่ได้มาตรฐาน** ตามที่ประกาศกำหนด
- [ ] PPE ต้องเหมาะสมกับ **ประเภทอันตราย** ในงานนั้น
- [ ] บำรุงรักษา ตรวจสอบ และเปลี่ยน PPE ที่ชำรุด
- [ ] อบรมลูกจ้างเรื่อง **การใช้และดูแลรักษา PPE**
- [ ] นายจ้างต้อง **ออกค่าใช้จ่าย PPE** ทั้งหมด (ห้ามให้ลูกจ้างออกเอง)
- [ ] บันทึกการจ่ายและรับ PPE

## การเลือก PPE ตามประเภทอันตราย
| อันตราย | PPE ที่ต้องใช้ |
|--------|-------------|
| วัสดุตกหล่น | หมวกนิรภัย, รองเท้านิรภัย |
| เสียงดัง (≥85 dB) | ที่อุดหู/ครอบหู |
| สารเคมี | ถุงมือ, แว่นตา, ชุดป้องกัน, หน้ากาก |
| งานเชื่อม | หน้ากากเชื่อม, ถุงมือ |
| งานไฟฟ้า | ถุงมือฉนวน, รองเท้าฉนวน |
| งานสูง | สายรัดนิรภัย |
| ฝุ่น/ก๊าซ | หน้ากากกรองฝุ่น/ก๊าซ |
