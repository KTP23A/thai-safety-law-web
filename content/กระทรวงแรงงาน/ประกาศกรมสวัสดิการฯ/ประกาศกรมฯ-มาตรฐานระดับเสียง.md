# ประกาศกรมฯ เรื่อง มาตรฐานระดับเสียงที่ยอมให้ลูกจ้างได้รับ

## สรุปสาระสำคัญ
กำหนด **ระดับเสียงสูงสุดที่ยอมให้ลูกจ้างได้รับ** ตลอดระยะเวลาการทำงานในแต่ละวัน โดยอ้างอิงหลัก Time-Weighted Average (TWA) และ Ceiling เพื่อป้องกันการสูญเสียการได้ยินจากการทำงาน

## ตารางระดับเสียงที่ยอมรับได้
| ระดับเสียง dB(A) | ระยะเวลาสูงสุดต่อวัน |
|----------------|------------------|
| 85 | 8 ชั่วโมง |
| 88 | 4 ชั่วโมง |
| 91 | 2 ชั่วโมง |
| 94 | 1 ชั่วโมง |
| 97 | 30 นาที |
| 100 | 15 นาที |
| 103 | 7.5 นาที |
| 106 | 3.75 นาที |
| ≥ 140 dB (peak) | ห้ามสัมผัสเลย |

## ค่า Action Level และ PEL
| ระดับ | ค่า | การดำเนินการ |
|-------|-----|------------|
| Action Level | 85 dB(A) TWA | เริ่มโปรแกรมอนุรักษ์การได้ยิน (HCP) |
| PEL | 90 dB(A) TWA | ต้องควบคุมเสียงทางวิศวกรรม |
| Ceiling | 140 dB peak | ห้ามสัมผัสโดยเด็ดขาด |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจวัดระดับเสียงในบริเวณที่คาดว่ามีเสียงดัง ≥ 85 dB(A) **อย่างน้อยปีละ 1 ครั้ง**
- [ ] จัดทำ **แผนที่เสียง (Noise Map)** ของสถานประกอบการ
- [ ] จัดให้ลูกจ้างที่รับเสียง ≥ 85 dB(A) สวม **อุปกรณ์ป้องกันเสียง**
- [ ] ดำเนินการ **โปรแกรมอนุรักษ์การได้ยิน (HCP)** สำหรับลูกจ้างในพื้นที่เสียงดัง
- [ ] ควบคุมเสียงโดยวิธีทางวิศวกรรม (Engineering Control) ก่อนใช้ PPE
