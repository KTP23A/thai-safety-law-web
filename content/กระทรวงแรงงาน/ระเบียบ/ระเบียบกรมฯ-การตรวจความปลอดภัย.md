# ระเบียบกรมฯ ว่าด้วยหลักเกณฑ์การตรวจความปลอดภัย

## สรุปสาระสำคัญ
กำหนดขั้นตอน หลักเกณฑ์ และแบบฟอร์มที่พนักงานตรวจแรงงานใช้ในการตรวจความปลอดภัยในสถานประกอบการ รวมถึงสิทธิของนายจ้างและลูกจ้างระหว่างการตรวจ

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] นายจ้างต้อง **อำนวยความสะดวก** แก่พนักงานตรวจแรงงาน
- [ ] จัดเตรียมเอกสาร: ทะเบียนลูกจ้าง แผนความปลอดภัย รายชื่อ จป.
- [ ] มีสิทธิ์ขอดู **ใบแต่งตั้งพนักงานตรวจ** ก่อนอนุญาตเข้าตรวจ
- [ ] ได้รับ **รายงานผลการตรวจ** หลังการตรวจเสร็จสิ้น
- [ ] แก้ไขข้อบกพร่องที่พบภายในกำหนดเวลาที่พนักงานตรวจกำหนด
