# กฎกระทรวงฯ เกี่ยวกับงานก่อสร้าง พ.ศ. 2564

## สรุปสาระสำคัญ
กำหนดมาตรฐานความปลอดภัยสำหรับงานก่อสร้าง ครอบคลุมนั่งร้าน งานที่สูง การขุดดิน เครื่องจักรก่อสร้าง และการป้องกันอันตรายในไซต์งาน

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] งานสูง **≥2 เมตร** ต้องมีราวกันตก หรือสายเบลท์นิรภัย
- [ ] นั่งร้านต้องออกแบบโดย **วิศวกร** และตรวจสอบก่อนใช้งาน
- [ ] ต้องสวม **หมวกนิรภัย** ตลอดเวลาในไซต์งาน
- [ ] การขุดดินลึก **≥1.5 เมตร** ต้องค้ำยันหรือลาดผนังดิน
- [ ] ติดตั้ง **รั้วกั้น** รอบไซต์งาน ป้ายเตือนอันตราย
- [ ] ห้ามทำงานใกล้สายไฟแรงสูงโดยไม่แจ้งการไฟฟ้า
- [ ] จัดให้มี **จป.เทคนิค** ประจำไซต์ตลอดเวลาทำงาน

## ผู้ที่เกี่ยวข้อง
- **ผู้รับเหมา/นายจ้าง:** จัดสภาพแวดล้อมปลอดภัย จัดหาอุปกรณ์ PPE
- **ลูกจ้าง/คนงานก่อสร้าง:** ต้องสวมใส่ PPE และปฏิบัติตามกฎความปลอดภัย
- **วิศวกร:** ต้องรับรองความปลอดภัยของโครงสร้างชั่วคราว

## บทลงโทษ
ฝ่าฝืน: ปรับไม่เกิน 500,000 บาท (ตาม [[พ.ร.บ.ความปลอดภัยอาชีวอนามัยฯ-2554]])

## มาตรฐานสำคัญ
| รายการ | ข้อกำหนด |
|--------|---------|
| งานที่สูง | ≥2 ม. ต้องมีราวกันตก/เบลท์ |
| นั่งร้าน | ออกแบบโดยวิศวกร, รับน้ำหนัก ≥4x โหลดใช้งาน |
| ขุดดิน | ≥1.5 ม. ต้องค้ำยัน |
| PPE บังคับ | หมวก รองเท้า เบลท์นิรภัย |
| จป. | ต้องมีประจำไซต์ตลอดเวลา |
