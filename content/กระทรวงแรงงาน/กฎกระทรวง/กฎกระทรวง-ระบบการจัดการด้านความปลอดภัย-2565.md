# กฎกระทรวงฯ เกี่ยวกับระบบการจัดการด้านความปลอดภัย พ.ศ. 2565

## สรุปสาระสำคัญ
กำหนดมาตรฐานระบบการจัดการด้านความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน (Safety Management System — SMS) สำหรับสถานประกอบการที่มีลูกจ้าง **50 คนขึ้นไป** ในกิจการที่กำหนด ต้องจัดให้มีระบบภายใน **60 วัน** นับแต่วันที่มีลูกจ้างครบจำนวน

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำ **นโยบายด้านความปลอดภัยและอาชีวอนามัย** เป็นลายลักษณ์อักษร
- [ ] กำหนด **โครงสร้างองค์กรด้านความปลอดภัย** บทบาท อำนาจ และหน้าที่
- [ ] จัดทำ **แผนงานด้านความปลอดภัย** และนำไปปฏิบัติจริง
- [ ] ประเมินผลและทบทวนระบบการจัดการ **อย่างน้อยปีละ 1 ครั้ง**
- [ ] บันทึก รายงาน และปรับปรุงระบบอย่างต่อเนื่อง
- [ ] สถานประกอบการ ≥50 คน ต้องจัดทำระบบภายใน **60 วัน**

## องค์ประกอบหลักของระบบ SMS
| องค์ประกอบ | รายละเอียด |
|-----------|-----------|
| 1. นโยบาย | ประกาศเป็นลายลักษณ์อักษร ผู้บริหารลงนาม |
| 2. การจัดองค์กร | กำหนดบทบาท อำนาจ ความรับผิดชอบ |
| 3. แผนงาน | กำหนดเป้าหมาย มาตรการ ระยะเวลา |
| 4. การนำไปปฏิบัติ | ฝึกอบรม ควบคุม ตรวจสอบ |
| 5. การประเมินผล | ตรวจประเมินภายใน ทบทวนโดยฝ่ายบริหาร |
| 6. การปรับปรุง | แก้ไขข้อบกพร่อง ป้องกันการเกิดซ้ำ |

## ผู้ที่เกี่ยวข้อง
- **นายจ้าง:** จัดทำและรักษาระบบ SMS ให้เป็นไปตามมาตรฐาน
- **ลูกจ้าง:** มีส่วนร่วมในระบบ ปฏิบัติตามขั้นตอน
- **หน่วยงานรัฐ:** กรมสวัสดิการฯ กำกับดูแลและตรวจสอบ
