# กฎกระทรวงฯ เกี่ยวกับการเป็นหน่วยงานฝึกอบรมดับเพลิงขั้นต้น พ.ศ. 2556

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์ วิธีการ และเงื่อนไขสำหรับ **การได้รับการรับรองเป็นหน่วยงานฝึกอบรมการดับเพลิงขั้นต้น** เพื่อให้สถานประกอบการสามารถจัดฝึกอบรมดับเพลิงขั้นต้นให้แก่ลูกจ้างเองได้ หรือให้หน่วยงานภายนอกที่ได้รับการรับรองมาจัดฝึกอบรม ตาม[[กฎกระทรวง-อัคคีภัย-2555]]

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] หน่วยงานที่จะจัดฝึกอบรมดับเพลิงต้อง **ยื่นขอรับรอง** จากกรมสวัสดิการฯ
- [ ] มี **วิทยากร** ที่ผ่านการอบรมหลักสูตรวิทยากรดับเพลิงของกรม
- [ ] มี **สถานที่และอุปกรณ์** สำหรับฝึกอบรมตามที่กำหนด รวมถึงอุปกรณ์ดับเพลิงจริง
- [ ] จัดการฝึกอบรมตาม **หลักสูตรที่กรมกำหนด** (ภาคทฤษฎีและภาคปฏิบัติ)
- [ ] ออก **วุฒิบัตร/ใบรับรอง** ให้แก่ผู้ผ่านการฝึกอบรม
- [ ] จัดทำรายงานผลการฝึกอบรมส่งกรมฯ

## หลักสูตรฝึกอบรมดับเพลิงขั้นต้น
| หัวข้อ | ชั่วโมง |
|--------|--------|
| ทฤษฎีอัคคีภัยและการป้องกัน | ภาคทฤษฎี |
| ประเภทของไฟและสารดับเพลิง | ภาคทฤษฎี |
| อุปกรณ์ดับเพลิงเบื้องต้น | ภาคปฏิบัติ |
| การใช้เครื่องดับเพลิงมือถือ | ภาคปฏิบัติ |
| การอพยพหนีไฟ | ภาคปฏิบัติ |
| **รวมทั้งหมด** | **ไม่น้อยกว่า 3 ชั่วโมง** |

## คุณสมบัติหน่วยงานฝึกอบรม
| ด้าน | ข้อกำหนด |
|------|---------|
| วิทยากร | ผ่านหลักสูตรวิทยากรดับเพลิงที่กรมรับรอง |
| สถานที่ | มีพื้นที่สำหรับฝึกปฏิบัติจริง |
| อุปกรณ์ | เครื่องดับเพลิงสำหรับฝึก ระบบสาธิต |
| เอกสาร | มีระบบออกใบรับรองและบันทึกข้อมูล |

## ผู้ที่เกี่ยวข้อง
- **หน่วยงานฝึกอบรม:** ยื่นขอรับรอง จัดฝึกอบรมตามมาตรฐาน
- **นายจ้าง:** ส่งลูกจ้างเข้าอบรมกับหน่วยงานที่ได้รับการรับรอง
- **กรมสวัสดิการฯ:** รับรองหน่วยงาน กำกับดูแลคุณภาพการฝึกอบรม
