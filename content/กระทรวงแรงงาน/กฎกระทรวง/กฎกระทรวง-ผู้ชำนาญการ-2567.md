# กฎกระทรวงฯ เกี่ยวกับการอนุญาตเป็นผู้ชำนาญการ พ.ศ. 2567

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์ วิธีการ และเงื่อนไขในการขอรับใบอนุญาตเป็น **ผู้ชำนาญการด้านความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน** เพื่อให้บริการแก่สถานประกอบการที่ต้องการผู้เชี่ยวชาญภายนอกในการจัดทำและบริหารระบบความปลอดภัย

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ผู้ประสงค์จะเป็นผู้ชำนาญการต้อง **ยื่นคำขอใบอนุญาต** ต่อกรมสวัสดิการฯ
- [ ] ต้องผ่าน **คุณสมบัติ** ด้านวุฒิการศึกษาและประสบการณ์ตามที่กำหนด
- [ ] ใบอนุญาต **มีอายุ 5 ปี** ต้องต่ออายุก่อนหมด
- [ ] ผู้ชำนาญการต้องปฏิบัติตาม **จรรยาบรรณ** และข้อกำหนดวิชาชีพ
- [ ] สถานประกอบการที่ใช้บริการผู้ชำนาญการต้องทำ **สัญญาจ้าง** ตามแบบที่กำหนด

## ผู้ที่เกี่ยวข้อง
- **ผู้ชำนาญการ (Expert):** ยื่นขอใบอนุญาต ต่ออายุ ปฏิบัติตามจรรยาบรรณ
- **นายจ้าง:** จ้างผู้ชำนาญการที่มีใบอนุญาตถูกต้องเท่านั้น
- **กรมสวัสดิการฯ:** ออกใบอนุญาต ต่ออายุ พักหรือเพิกถอนใบอนุญาต

## คุณสมบัติผู้ชำนาญการ
| ด้าน | ข้อกำหนด |
|------|---------|
| วุฒิการศึกษา | ปริญญาตรีขึ้นไป สาขาที่เกี่ยวข้อง |
| ประสบการณ์ | ทำงานด้านความปลอดภัยไม่น้อยกว่าที่กำหนด |
| การอบรม | ผ่านหลักสูตรที่กรมสวัสดิการฯ รับรอง |
| อายุใบอนุญาต | 5 ปี (ต่ออายุได้) |

## บทลงโทษ
- ประกอบกิจการโดยไม่มีใบอนุญาต: ปรับและ/หรือจำคุก (ตาม [[พ.ร.บ.ความปลอดภัยอาชีวอนามัยฯ-2554]])
- ฝ่าฝืนเงื่อนไขใบอนุญาต: พักหรือเพิกถอนใบอนุญาต
