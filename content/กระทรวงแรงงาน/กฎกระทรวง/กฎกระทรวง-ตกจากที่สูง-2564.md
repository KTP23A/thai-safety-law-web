# กฎกระทรวงฯ เกี่ยวกับการป้องกันการตกจากที่สูงและวัสดุตกหล่น พ.ศ. 2564

## สรุปสาระสำคัญ
กำหนดมาตรฐานในการบริหาร จัดการ และดำเนินการด้านความปลอดภัยสำหรับงานที่มีความเสี่ยงต่อ **การตกจากที่สูง** และการเป็นอันตรายจาก **วัสดุที่กระเด็น ตกหล่น หรือพังทลาย** รวมถึงความปลอดภัยของ **ภาชนะบรรจุและรองรับวัสดุ**

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ติดตั้ง **ราวกันตก (guardrail)** ความสูงไม่น้อยกว่า 90 ซม. ในพื้นที่เสี่ยงสูง
- [ ] ติดตั้ง **ตาข่ายนิรภัย (safety net)** สำหรับงานที่ไม่สามารถติดราวได้
- [ ] จัดให้ลูกจ้างสวม **สายรัดนิรภัย (safety harness)** พร้อมอุปกรณ์ยึดเหนี่ยว
- [ ] ติดตั้ง **กันชนขอบพื้น (toe board)** เพื่อป้องกันวัสดุตกหล่น
- [ ] กำหนด **เขตห้ามเข้า** บริเวณใต้งานที่กำลังดำเนินการในที่สูง
- [ ] ตรวจสอบความมั่นคงแข็งแรงของ **ภาชนะบรรจุวัสดุ** ก่อนใช้งาน
- [ ] จัดทำ **แผนป้องกัน** การตกจากที่สูงก่อนเริ่มงาน

## มาตรฐานราวกันตก
| องค์ประกอบ | ข้อกำหนด |
|-----------|---------|
| ความสูงราวบน | ≥ 90 ซม. จากพื้น |
| ราวกลาง | ที่ความสูง ~45 ซม. |
| กันชนขอบพื้น | ≥ 10 ซม. |
| ความทนแรง | รับแรงกระแทก ≥ 200 กก. |

## สายรัดนิรภัย
| ประเภท | การใช้งาน |
|--------|----------|
| Full Body Harness | งานทั่วไปในที่สูง |
| Retractable Lanyard | งานที่ต้องเคลื่อนที่มาก |
| จุดยึด (Anchor Point) | รับแรง ≥ 2,300 กก. |

## ผู้ที่เกี่ยวข้อง
- **นายจ้าง:** ติดตั้งระบบป้องกัน จัดหาอุปกรณ์ อบรมลูกจ้าง
- **จป.วิชาชีพ:** ตรวจสอบและให้คำแนะนำด้านความปลอดภัย
- **ลูกจ้าง:** สวมอุปกรณ์ป้องกันและปฏิบัติตามขั้นตอน
