# กฎกระทรวงฯ เกี่ยวกับการขึ้นทะเบียนและอนุญาตหน่วยบริการด้านความปลอดภัย พ.ศ. 2564

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์ วิธีการ และเงื่อนไขในการ **ขึ้นทะเบียนและได้รับใบอนุญาต** สำหรับหน่วยงานหรือบุคคลที่ให้บริการด้านความปลอดภัย อาชีวอนามัย และสภาพแวดล้อมในการทำงาน เพื่อส่งเสริมและสนับสนุนสถานประกอบการในการดำเนินงานด้านความปลอดภัย

## ประเภทหน่วยบริการที่ต้องขึ้นทะเบียน
| ประเภท | รายละเอียด |
|--------|-----------|
| หน่วยตรวจสอบและรับรอง | ตรวจสอบ ทดสอบ รับรองด้านความปลอดภัย |
| หน่วยฝึกอบรม | จัดฝึกอบรมหลักสูตรด้านความปลอดภัยที่กรมรับรอง |
| หน่วยให้คำปรึกษา | บริการให้คำปรึกษาแนะนำระบบความปลอดภัย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ยื่นคำขอขึ้นทะเบียน/ใบอนุญาตต่อ **กรมสวัสดิการและคุ้มครองแรงงาน**
- [ ] มีคุณสมบัติ บุคลากร และอุปกรณ์ตามที่กำหนด
- [ ] จัดทำรายงานผลการให้บริการส่งกรมฯ ตามกำหนด
- [ ] ต่ออายุใบอนุญาตก่อนหมดอายุ
- [ ] ห้ามให้บริการเกินขอบเขตที่ได้รับอนุญาต

## คุณสมบัติหน่วยบริการ
| ด้าน | ข้อกำหนด |
|------|---------|
| บุคลากร | มีผู้เชี่ยวชาญที่มีคุณวุฒิตามประเภทบริการ |
| อุปกรณ์/เครื่องมือ | พร้อมและได้รับการสอบเทียบมาตรฐาน |
| สถานที่ | มีสถานที่ปฏิบัติงานเหมาะสม |
| ระบบงาน | มีระบบประกันคุณภาพ |

## ผู้ที่เกี่ยวข้อง
- **หน่วยบริการ:** ยื่นขอขึ้นทะเบียน ปฏิบัติตามเงื่อนไข จัดทำรายงาน
- **นายจ้าง:** ใช้บริการจากหน่วยที่ขึ้นทะเบียนแล้วเท่านั้น
- **กรมสวัสดิการฯ:** ออกใบอนุญาต กำกับดูแล ต่ออายุ/เพิกถอน

## บทลงโทษ
- ให้บริการโดยไม่มีใบอนุญาต: ปรับและ/หรือจำคุกตาม [[พ.ร.บ.ความปลอดภัยอาชีวอนามัยฯ-2554]]
- ฝ่าฝืนเงื่อนไข: พักหรือเพิกถอนใบอนุญาต
