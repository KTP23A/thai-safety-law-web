# กฎกระทรวงฯ เกี่ยวกับการตรวจสุขภาพลูกจ้าง พ.ศ. 2563

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์และวิธีการ **ตรวจสุขภาพลูกจ้าง** ที่ทำงานสัมผัสกับปัจจัยเสี่ยงด้านสุขภาพ เพื่อเฝ้าระวังสุขภาพ ป้องกัน และค้นหาโรคจากการทำงานตั้งแต่ระยะเริ่มต้น พร้อมกำหนดให้นายจ้างส่งผลการตรวจแก่พนักงานตรวจความปลอดภัย

## ประเภทปัจจัยเสี่ยงที่ต้องตรวจสุขภาพ
| ปัจจัย | ตัวอย่าง |
|--------|---------|
| สารเคมีอันตราย | ตะกั่ว, สารปรอท, สารเบนซีน, สารทำละลาย |
| ฝุ่นทำให้เกิดโรค | ฝุ่นซิลิกา, ฝุ่นแร่ใยหิน, ฝุ่นถ่านหิน |
| สารก่อมะเร็ง | แร่ใยหิน, เบนซีน, ฟอร์มาลดีไฮด์ |
| รังสี | รังสีชนิดก่อไอออน |
| เสียงดัง | เสียงเกิน 85 dB(A) |
| ความสั่นสะเทือน | การทำงานกับเครื่องมือสั่น |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดให้มีการตรวจสุขภาพ **ก่อนเข้าทำงาน** (Pre-employment) สำหรับลูกจ้างในงานเสี่ยง
- [ ] จัดให้มีการตรวจสุขภาพ **ประจำปี** (Annual medical exam) ตลอดระยะเวลาที่ทำงานสัมผัสปัจจัยเสี่ยง
- [ ] จัดให้มีการตรวจสุขภาพ **เมื่อออกจากงาน** หรือย้ายออกจากพื้นที่เสี่ยง
- [ ] ใช้แพทย์อาชีวเวชศาสตร์ หรือแพทย์ที่ผ่านการอบรมด้านอาชีวเวชศาสตร์
- [ ] บันทึกผลการตรวจสุขภาพ **เก็บไว้ไม่น้อยกว่า 5 ปี** (กรณีสารก่อมะเร็ง 30 ปี)
- [ ] ส่งผลการตรวจสุขภาพแก่ **พนักงานตรวจความปลอดภัย** ตามกำหนด
- [ ] แจ้งผลการตรวจสุขภาพแก่ **ลูกจ้าง** เป็นรายบุคคล

## รายการตรวจตามปัจจัยเสี่ยง
| ปัจจัยเสี่ยง | รายการตรวจพิเศษ |
|------------|---------------|
| ตะกั่ว | ระดับตะกั่วในเลือด (Blood Lead Level) |
| เสียงดัง | การตรวจการได้ยิน (Audiometry) |
| ซิลิกา/แร่ใยหิน | X-ray ปอด, Spirometry |
| สารทำละลาย | ตับ, ไต (LFT, KFT) |
| รังสี | CBC, ตรวจดวงตา |

## ผู้ที่เกี่ยวข้อง
- **นายจ้าง:** จัดและรับผิดชอบค่าใช้จ่ายในการตรวจสุขภาพ
- **แพทย์อาชีวเวชศาสตร์:** ดำเนินการตรวจและประเมินผล
- **จป.วิชาชีพ:** ติดตาม รวบรวมผล แจ้งข้อเสนอแนะ
- **ลูกจ้าง:** รับการตรวจสุขภาพตามกำหนด
