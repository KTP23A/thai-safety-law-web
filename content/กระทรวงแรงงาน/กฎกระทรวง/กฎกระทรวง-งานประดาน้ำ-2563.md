# กฎกระทรวงฯ เกี่ยวกับงานประดาน้ำ พ.ศ. 2563

## สรุปสาระสำคัญ
กำหนดมาตรฐานในการ **บริหาร จัดการ และดำเนินการด้านความปลอดภัย** สำหรับงานประดาน้ำในสถานประกอบการ ครอบคลุมการดำน้ำทั้งประเภทสกูบา (SCUBA) การดำน้ำแบบผิวน้ำส่งอากาศ (Surface-supplied diving) และการดำน้ำลึก เพื่อป้องกันอันตรายจากแรงดัน ก๊าซพิษ และการจมน้ำ

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ผู้ดำน้ำต้องมี **ใบรับรองการดำน้ำ** จากสถาบันที่ได้รับการรับรอง
- [ ] จัดทำ **แผนการดำน้ำ (Dive Plan)** ก่อนเริ่มปฏิบัติงานทุกครั้ง
- [ ] จัดให้มี **ผู้ควบคุมการดำน้ำ (Dive Supervisor)** ตลอดการปฏิบัติงาน
- [ ] มี **นักประดาน้ำสำรอง (Standby Diver)** พร้อมช่วยเหลือตลอดเวลา
- [ ] จัดหา **อุปกรณ์ดำน้ำมาตรฐาน** ตรวจสอบก่อนใช้งาน
- [ ] ห้ามดำน้ำเดี่ยว (Solo diving) ในงานประดาน้ำเชิงอุตสาหกรรม
- [ ] มีแผน **ฉุกเฉินและช่วยเหลือ** พร้อมอุปกรณ์ปฐมพยาบาล
- [ ] จัดให้มีออกซิเจน **100%** สำหรับกรณีฉุกเฉิน
- [ ] บันทึก **สมุดบันทึกการดำน้ำ (Dive Log)** ทุกครั้ง

## ขีดจำกัดการดำน้ำ
| ประเภทงาน | ความลึกสูงสุด |
|----------|-------------|
| SCUBA อากาศ | ≤ 40 เมตร |
| Surface-supplied อากาศ | ≤ 50 เมตร |
| ก๊าซผสม (Mixed gas) | ตามการวางแผน |
| Decompression dive | ต้องมีการลดความดันตามตาราง |

## บุคลากรที่ต้องจัดให้มี
| ตำแหน่ง | หน้าที่ |
|---------|--------|
| ผู้ควบคุมการดำน้ำ (Dive Supervisor) | วางแผน ควบคุม ตัดสินใจ |
| นักประดาน้ำ (Diver) | ปฏิบัติงานใต้น้ำ |
| นักประดาน้ำสำรอง (Standby Diver) | พร้อมช่วยเหลือ ≥ 1 คน |
| ผู้ช่วยบนผิวน้ำ (Tender) | ดูแลสายอากาศ สาย lifeline |

## ผู้ที่เกี่ยวข้อง
- **นายจ้าง:** จัดหาอุปกรณ์มาตรฐาน อบรมบุคลากร จัดทำแผนฉุกเฉิน
- **ผู้ควบคุมการดำน้ำ:** วางแผน ตัดสินใจหยุดดำน้ำหากไม่ปลอดภัย
- **นักประดาน้ำ:** ปฏิบัติตามแผน รายงานสภาพใต้น้ำ

## บทลงโทษ
ฝ่าฝืน: ปรับไม่เกิน 200,000 บาท และ/หรือจำคุก (ตาม [[พ.ร.บ.ความปลอดภัยอาชีวอนามัยฯ-2554]])
