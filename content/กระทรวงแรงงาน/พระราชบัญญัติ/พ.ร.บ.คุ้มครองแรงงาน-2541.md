# พระราชบัญญัติคุ้มครองแรงงาน พ.ศ. 2541

## สรุปสาระสำคัญ
กฎหมายพื้นฐานด้านแรงงานที่กำหนด **สิทธิและหน้าที่ของนายจ้างและลูกจ้าง** ครอบคลุมตั้งแต่การกำหนดค่าจ้างขั้นต่ำ เวลาทำงานปกติ การทำงานล่วงเวลา วันหยุด วันลา สวัสดิการ ไปจนถึงค่าชดเชยเมื่อเลิกจ้าง บังคับใช้กับ **นายจ้างทุกประเภทและทุกขนาด** ที่มีลูกจ้างตั้งแต่ 1 คนขึ้นไป ยกเว้นราชการและรัฐวิสาหกิจที่มีกฎหมายเฉพาะ

## ขอบเขตการบังคับใช้
| เกณฑ์ | รายละเอียด |
|-------|-----------|
| ผู้มีหน้าที่ | นายจ้างทุกประเภท (เอกชน) ที่มีลูกจ้างตั้งแต่ 1 คน |
| ยกเว้น | ราชการ / รัฐวิสาหกิจ (ใช้กฎหมายเฉพาะ) |
| ลูกจ้างประเภทพิเศษ | แรงงานบ้าน, ลูกจ้างเกษตรกรรม (มีเงื่อนไขพิเศษ) |

## ข้อกำหนดสำคัญ

### เวลาทำงาน
| ประเภทงาน | ชั่วโมงปกติ |
|-----------|------------|
| งานทั่วไป | ≤ 8 ชั่วโมง/วัน, ≤ 48 ชั่วโมง/สัปดาห์ |
| งานอันตราย (สารเคมี, ฝุ่น, เสียงดัง) | ≤ 7 ชั่วโมง/วัน, ≤ 42 ชั่วโมง/สัปดาห์ |
| ล่วงเวลา | ≤ 36 ชั่วโมง/สัปดาห์ (ต้องได้รับความยินยอม) |

### ค่าตอบแทน
| ประเภท | อัตรา |
|--------|-------|
| ค่าจ้างปกติ | ≥ อัตราค่าจ้างขั้นต่ำตามประกาศคณะกรรมการค่าจ้าง |
| ล่วงเวลาวันทำงาน | × 1.5 เท่า |
| ทำงานวันหยุด | × 2 เท่า |
| ล่วงเวลาวันหยุด | × 3 เท่า |

### วันหยุดและวันลา
| ประเภท | สิทธิ |
|--------|-------|
| วันหยุดประจำสัปดาห์ | ≥ 1 วัน/สัปดาห์ |
| วันหยุดตามประเพณี | ≥ 13 วัน/ปี (รวมวันแรงงานแห่งชาติ) |
| วันลาพักผ่อนประจำปี | ≥ 6 วัน/ปี (ทำงานครบ 1 ปี) |
| วันลาป่วย | ≤ 30 วัน/ปี (ได้รับค่าจ้าง) |
| วันลาคลอด | ≤ 98 วัน/ครรภ์ (ได้รับค่าจ้าง 45 วัน) |
| วันลากิจ | ≥ 3 วัน/ปี (ฉ.7 ปี 2562) |

### ค่าชดเชยเมื่อเลิกจ้าง
| อายุงาน | ค่าชดเชย |
|---------|---------|
| 120 วัน – < 1 ปี | 30 วันสุดท้าย |
| 1 ปี – < 3 ปี | 90 วัน |
| 3 ปี – < 6 ปี | 180 วัน |
| 6 ปี – < 10 ปี | 240 วัน |
| 10 ปี – < 20 ปี | 300 วัน |
| ≥ 20 ปี | 400 วัน (ฉ.7 ปี 2562) |

### ความปลอดภัยและสวัสดิการ
- นายจ้างต้องจัดสถานที่ทำงานให้มีสภาพที่ปลอดภัยต่อสุขภาพ
- ต้องจัดให้มีน้ำสะอาด ห้องน้ำ และสิ่งอำนวยความสะดวกขั้นพื้นฐาน
- ต้องจัดทำทะเบียนลูกจ้างและบันทึกเวลาทำงาน

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำทะเบียนลูกจ้าง และบันทึกข้อมูลครบถ้วน
- [ ] จัดทำสัญญาจ้างที่ถูกต้องตามกฎหมาย
- [ ] กำหนดเวลาทำงานไม่เกินที่กฎหมายกำหนด (8 ชม./วัน หรือ 7 ชม. สำหรับงานอันตราย)
- [ ] จ่ายค่าจ้างไม่น้อยกว่าค่าแรงขั้นต่ำตามประกาศปัจจุบัน
- [ ] จ่ายค่าล่วงเวลาและค่าทำงานวันหยุดในอัตราที่กำหนด
- [ ] จัดวันหยุดประจำสัปดาห์ ≥ 1 วัน
- [ ] จัดวันหยุดตามประเพณี ≥ 13 วัน/ปี และแจ้งล่วงหน้า
- [ ] จัดวันลาพักผ่อนประจำปี ≥ 6 วัน/ปี สำหรับพนักงานที่ทำงานครบ 1 ปี
- [ ] จัดระบบลาป่วย ลาคลอด ลากิจตามสิทธิที่กำหนด
- [ ] จัดสถานที่ทำงานให้ปลอดภัยและถูกสุขลักษณะ
- [ ] กรณีเลิกจ้าง — จ่ายค่าชดเชยตามอายุงานและค่าจ้างแทนการบอกกล่าวล่วงหน้า
