# พระราชบัญญัติควบคุมน้ำมันเชื้อเพลิง พ.ศ. 2542

## สรุปสาระสำคัญ
**กฎหมายแม่** สำหรับการควบคุมน้ำมันเชื้อเพลิงและก๊าซปิโตรเลียมเหลว (LPG) ในประเทศไทย กำหนดมาตรการความปลอดภัยสำหรับการผลิต จัดเก็บ ขนส่ง และจำหน่าย น้ำมันเชื้อเพลิงและก๊าซทุกประเภท รวมถึงการขออนุญาตประกอบกิจการที่เกี่ยวข้อง

## ขอบเขตการบังคับใช้
| ประเภทกิจการ | ข้อกำหนด |
|------------|-----------|
| คลังน้ำมัน | ต้องขออนุญาต + ปฏิบัติตามมาตรฐานความปลอดภัย |
| สถานีบริการน้ำมัน | ต้องขออนุญาต + ตรวจสอบประจำปี |
| สถานที่เก็บ LPG | ต้องขออนุญาตตามปริมาณที่เก็บ |
| โรงบรรจุ LPG | ต้องขออนุญาต + มาตรฐานพิเศษ |
| สถานที่ใช้ก๊าซธรรมชาติ | ต้องปฏิบัติตามประกาศกระทรวง |

## โครงสร้างกฎหมายลูก (อนุบัญญัติสำคัญ)
- [[กฎกระทรวง-คลังน้ำมัน-2556]] — มาตรฐานความปลอดภัยคลังน้ำมันเชื้อเพลิง
- [[กฎกระทรวง-ระบบไฟฟ้าสถานีน้ำมัน-2556]] — ระบบไฟฟ้าและป้องกันฟ้าผ่าสถานีน้ำมัน
- [[กฎกระทรวง-LPG-สถานที่ใช้-2562]] — สถานที่เก็บรักษา LPG ประเภทสถานที่ใช้
- [[กฎกระทรวง-LPG-โรงบรรจุ-2564]] — สถานที่บรรจุ LPG ประเภทโรงบรรจุ
- [[ประกาศกระทรวง-ก๊าซธรรมชาติ-ความปลอดภัย-2550]] — ความปลอดภัยสถานที่ใช้ก๊าซธรรมชาติ

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าสถานที่เก็บ LPG / น้ำมันในโรงงานมีใบอนุญาตถูกต้อง
- [ ] ปฏิบัติตามกฎกระทรวงที่ออกตาม พ.ร.บ. นี้
- [ ] ต่ออายุใบอนุญาตประกอบกิจการตามกำหนด
- [ ] แจ้งการเปลี่ยนแปลงสถานที่เก็บต่อกรมธุรกิจพลังงาน
