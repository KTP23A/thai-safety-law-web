# พระราชบัญญัติการประกอบกิจการพลังงาน พ.ศ. 2550

## สรุปสาระสำคัญ
กำหนด **กรอบกำกับดูแลกิจการพลังงาน** ได้แก่ กิจการไฟฟ้า (ผลิต ส่ง จำหน่าย) และกิจการก๊าซธรรมชาติ (ท่อส่ง จำหน่าย LNG) โดยจัดตั้ง **คณะกรรมการกำกับกิจการพลังงาน (กกพ.)** เป็นองค์กรกำกับดูแลอิสระ ผู้ประกอบกิจการต้องได้รับ **ใบอนุญาต (License)** และปฏิบัติตามกฎระเบียบของ กกพ.

## ขอบเขตกิจการที่ต้องขออนุญาต
| ประเภทกิจการ | รายละเอียด |
|-------------|-----------|
| ผลิตไฟฟ้า | โรงไฟฟ้าขนาด > 1,000 kW |
| ระบบส่งไฟฟ้า | สายส่งแรงสูง (เป็น กฟผ. ดำเนินการ) |
| ระบบจำหน่ายไฟฟ้า | กฟน. / กฟภ. / ผู้ได้รับสัมปทาน |
| จำหน่ายไฟฟ้า | ผู้ค้าไฟฟ้าและผู้จำหน่ายตรง |
| ระบบท่อก๊าซธรรมชาติ | ท่อส่งก๊าซฯ และสถานี LNG |
| จำหน่ายก๊าซธรรมชาติ | ผ่านท่อและ NGV station |

## ผู้ที่ได้รับผลกระทบโดยตรง (Relevant Business)
- **โรงงานที่ผลิตไฟฟ้าใช้เอง (Cogeneration/SPP/VSPP)** — ต้องขออนุญาตผลิต
- **นิคมอุตสาหกรรม** — กรณีจำหน่ายไฟฟ้าให้ผู้เช่าพื้นที่ ต้องมีใบอนุญาต
- **ผู้พัฒนาพลังงานหมุนเวียน** — Solar, Wind, Biomass ขนาด > 1 MW
- **ผู้ค้าก๊าซธรรมชาติ** — NGV / LNG Station

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| ใบอนุญาต | ต้องได้รับใบอนุญาตจาก กกพ. ก่อนประกอบกิจการ |
| การต่ออายุ | ต้องต่ออายุใบอนุญาตตามกำหนด |
| รายงาน | รายงานผลการดำเนินงานต่อ กกพ. ตามระยะเวลาที่กำหนด |
| มาตรฐานบริการ | ต้องปฏิบัติตามมาตรฐานคุณภาพบริการ กกพ. |
| อัตราค่าบริการ | กกพ. กำกับอัตราค่าบริการ (Tariff) |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่ากิจการที่ดำเนินการเข้าข่ายต้องขออนุญาตจาก กกพ. หรือไม่
- [ ] หากมีโรงไฟฟ้า Cogeneration/Solar/Biomass ขนาด > 1,000 kW — ต้องมีใบอนุญาตผลิตไฟฟ้า
- [ ] หากจำหน่ายไฟฟ้าภายในนิคมหรือพื้นที่ — ต้องมีใบอนุญาตจำหน่ายไฟฟ้า
- [ ] ตรวจสอบใบอนุญาตยังไม่หมดอายุและเป็นปัจจุบัน
- [ ] ปฏิบัติตามมาตรฐานคุณภาพบริการและรายงานตาม กกพ.
