# กฎกระทรวงสถานที่เก็บรักษาก๊าซปิโตรเลียมเหลวประเภทสถานที่ใช้ พ.ศ. 2562

## สรุปสาระสำคัญ
กำหนด **มาตรฐานความปลอดภัยสำหรับสถานที่ใช้ LPG** เช่น โรงงาน ร้านอาหาร โรงแรม ที่มีการเก็บรักษาถัง LPG ไว้ใช้งาน กำหนดปริมาณสูงสุดที่เก็บได้ ระยะห่างความปลอดภัย ระบบป้องกันอัคคีภัย และข้อกำหนดการติดตั้ง

## การจำแนกประเภทตามปริมาณ LPG
| ประเภท | ปริมาณ LPG ที่เก็บ | ข้อกำหนด |
|--------|------------------|-----------|
| ขนาดเล็ก | ≤ 48 กก. (ถัง 15 กก. ≤ 3 ถัง) | ข้อกำหนดพื้นฐาน |
| ขนาดกลาง | 48–1,000 กก. | ต้องขออนุญาต |
| ขนาดใหญ่ | >1,000 กก. | ต้องขออนุญาต + ตรวจสอบพิเศษ |

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| ระยะห่าง | ห่างจากแหล่งความร้อน/ไฟตามที่กำหนด |
| การระบายอากาศ | บริเวณเก็บถังต้องระบายอากาศได้ดี |
| ป้ายเตือน | ติดป้าย "ห้ามจุดไฟ" และ "ระวังอันตราย" |
| อุปกรณ์ดับเพลิง | ต้องมีถังดับเพลิงประจำจุดเก็บ LPG |
| ท่อและข้อต่อ | ต้องเป็นมาตรฐาน ไม่รั่วซึม |
| การตรวจสอบ | ตรวจสอบสภาพถังและอุปกรณ์เป็นประจำ |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบปริมาณ LPG ที่เก็บ — หากเกิน 48 กก. ต้องขออนุญาต DOEB
- [ ] ตรวจสอบระยะห่างระหว่างถัง LPG กับแหล่งความร้อน/ไฟ
- [ ] ตรวจสอบการระบายอากาศในพื้นที่เก็บถัง LPG
- [ ] ติดป้ายเตือนอันตรายครบทุกจุดเก็บ LPG
- [ ] ตรวจสอบสภาพถัง ท่อ และข้อต่อไม่ให้รั่ว (soap test)
- [ ] จัดให้มีถังดับเพลิงที่เหมาะสมประจำพื้นที่เก็บ LPG
