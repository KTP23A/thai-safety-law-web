# กฎกระทรวงระบบไฟฟ้าและระบบป้องกันอันตรายจากฟ้าผ่าของสถานที่ประกอบกิจการน้ำมัน พ.ศ. 2556

## สรุปสาระสำคัญ
กำหนด **มาตรฐานระบบไฟฟ้าและระบบป้องกันฟ้าผ่า** สำหรับสถานที่ประกอบกิจการน้ำมัน (คลังน้ำมัน สถานีบริการ) ซึ่งเป็นพื้นที่อันตราย (Hazardous Area) เนื่องจากมีไอระเหยน้ำมันที่ติดไฟได้ ครอบคลุมมาตรฐานอุปกรณ์ไฟฟ้า การต่อลงดิน และระบบสายล่อฟ้า

## ข้อกำหนดสำคัญ
| ระบบ | ข้อกำหนด |
|------|-----------|
| อุปกรณ์ไฟฟ้า | ต้องเป็น Explosion-proof (Ex) ในพื้นที่ Hazardous Zone |
| การจำแนก Zone | Zone 0 / Zone 1 / Zone 2 ตามความเสี่ยงไอระเหย |
| ระบบต่อลงดิน (Earthing) | ต้องต่อลงดินทุกถัง ท่อ และอุปกรณ์โลหะ |
| สายล่อฟ้า | บังคับสำหรับถังน้ำมันและอาคารในคลังน้ำมัน |
| Static Bonding | ระหว่างรถบรรทุกและจุดรับจ่ายน้ำมัน |
| ป้าย | ห้ามใช้โทรศัพท์ / ห้ามจุดไฟในพื้นที่อันตราย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าอุปกรณ์ไฟฟ้าในพื้นที่ Hazardous Zone เป็น Explosion-proof (Ex)
- [ ] ตรวจสอบและทดสอบระบบต่อลงดิน (Earth Resistance ≤10 Ω)
- [ ] ตรวจสอบสายล่อฟ้าบนถังน้ำมันและอาคาร
- [ ] ตรวจสอบ Static Bonding Cable ที่จุดรับจ่ายน้ำมัน
- [ ] บำรุงรักษาและทดสอบระบบไฟฟ้าตามรอบที่กำหนด
- [ ] จัดทำแผนผัง Hazardous Area Classification
