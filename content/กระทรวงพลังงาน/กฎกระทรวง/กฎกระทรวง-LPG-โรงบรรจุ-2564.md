# กฎกระทรวงสถานที่บรรจุก๊าซปิโตรเลียมเหลวประเภทโรงบรรจุ พ.ศ. 2564

## สรุปสาระสำคัญ
กำหนด **มาตรฐานความปลอดภัยสำหรับโรงบรรจุก๊าซ LPG** (สถานที่ถ่ายเทก๊าซจากถังขนาดใหญ่ลงถังหุงต้มขนาดเล็ก) ครอบคลุมการออกแบบสถานที่ ระบบป้องกันอัคคีภัย ระบบไฟฟ้า อุปกรณ์บรรจุ ระยะห่างความปลอดภัย และการฝึกอบรมพนักงาน

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| สถานที่ | ต้องได้รับอนุญาต + ตรวจสอบก่อนเปิดดำเนินการ |
| ระบบดับเพลิง | Water Curtain + Foam สำหรับถังเก็บ LPG |
| อุปกรณ์ไฟฟ้า | Explosion-proof ทุกชิ้นในพื้นที่ Hazardous Zone |
| ระยะห่าง | กำหนดระยะห่างถังเก็บจากอาคาร แนวเขต ถนน |
| เครื่องบรรจุ | มาตรฐานตาชั่งและวาล์วป้องกันการรั่ว |
| พนักงาน | ผ่านการฝึกอบรมและได้รับการรับรอง |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบใบอนุญาตโรงบรรจุจากกรมธุรกิจพลังงาน
- [ ] ตรวจสอบระบบ Water Curtain และ Foam System ให้พร้อมใช้งาน
- [ ] ตรวจสอบอุปกรณ์ไฟฟ้าในพื้นที่อันตราย (Hazardous Zone)
- [ ] ตรวจสอบเครื่องชั่งและอุปกรณ์บรรจุตามกำหนด
- [ ] จัดให้มีพนักงานที่ผ่านการฝึกอบรมตามที่กฎกระทรวงกำหนด
- [ ] ซ้อมแผนฉุกเฉินสำหรับเหตุก๊าซรั่วและอัคคีภัย
