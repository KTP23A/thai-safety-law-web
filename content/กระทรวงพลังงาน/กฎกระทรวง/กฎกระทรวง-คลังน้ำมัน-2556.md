# กฎกระทรวงคลังน้ำมัน พ.ศ. 2556

## สรุปสาระสำคัญ
กำหนด **มาตรฐานความปลอดภัยสำหรับคลังน้ำมันเชื้อเพลิง** ครอบคลุมการออกแบบ ก่อสร้าง และดำเนินการคลังน้ำมัน รวมถึงมาตรฐานถังเก็บน้ำมัน ระบบป้องกันอัคคีภัย ระบบกักเก็บน้ำมันรั่ว ระยะห่างความปลอดภัย และข้อกำหนดบุคลากร

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| ถังเก็บน้ำมัน | มาตรฐานการออกแบบ วัสดุ และการตรวจสอบ |
| Bund Wall | ต้องมีคันกั้นรอบถังน้ำมัน รับปริมาตรได้ 110% |
| ระบบดับเพลิง | Foam System สำหรับถังน้ำมันขนาดใหญ่ |
| ระยะห่าง | กำหนดระยะห่างระหว่างถัง อาคาร และแนวเขต |
| การตรวจสอบ | ตรวจสอบถังและอุปกรณ์ตามรอบที่กำหนด |
| ผู้ควบคุม | ต้องมีผู้ควบคุมที่ผ่านการอบรมประจำคลัง |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่า Bund Wall รอบถังน้ำมันอยู่ในสภาพดีและไม่มีรอยรั่ว
- [ ] ตรวจสอบและทดสอบระบบดับเพลิง (Foam System) ตามกำหนด
- [ ] ตรวจสอบถังน้ำมันตามรอบที่กฎกระทรวงกำหนด
- [ ] ตรวจสอบระยะห่างความปลอดภัยระหว่างถังและสิ่งก่อสร้าง
- [ ] จัดให้มีผู้ควบคุมคลังน้ำมันที่ผ่านการอบรม
- [ ] บันทึกปริมาณน้ำมันและรายงานตามที่กำหนด
