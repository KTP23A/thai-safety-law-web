# พระราชบัญญัติป้องกันและบรรเทาสาธารณภัย พ.ศ. 2550

## สรุปสาระสำคัญ
**กฎหมายแม่** สำหรับระบบป้องกันและบรรเทาสาธารณภัยแห่งชาติ กำหนดโครงสร้างการบัญชาการ หน้าที่ของหน่วยงานทุกระดับ (ชาติ — จังหวัด — อำเภอ — ท้องถิ่น) ในการจัดการกับสาธารณภัยทุกประเภท รวมถึงอัคคีภัย อุทกภัย ภัยแล้ง และภัยพิบัติอื่น ๆ

## ขอบเขตและสาธารณภัยที่ครอบคลุม
| ประเภทสาธารณภัย | ตัวอย่าง |
|----------------|---------|
| ภัยธรรมชาติ | อุทกภัย ภัยแล้ง พายุ แผ่นดินไหว |
| อัคคีภัย | ไฟไหม้อาคาร โรงงาน คลังสินค้า |
| ภัยจากสารเคมี | การรั่วไหลของสารเคมีอันตราย |
| ภัยจากการคมนาคม | อุบัติเหตุขนส่งวัตถุอันตราย |

## หน้าที่สำคัญของโรงงาน/สถานประกอบการ
| ข้อกำหนด | รายละเอียด |
|---------|-----------|
| แผนป้องกันสาธารณภัย | ต้องมีแผนฉุกเฉินสำหรับอัคคีภัยและภัยพิบัติ |
| ประสานกับท้องถิ่น | แจ้งข้อมูลความเสี่ยงต่อหน่วยงานท้องถิ่น |
| ให้ความร่วมมือ | ต้องให้ความร่วมมือเมื่อเกิดสาธารณภัย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำแผนป้องกันและระงับอัคคีภัยสำหรับโรงงาน/คลังสินค้า
- [ ] แจ้งข้อมูลวัตถุอันตรายในสถานประกอบการต่อหน่วยงานท้องถิ่น
- [ ] ซ้อมแผนฉุกเฉินและอพยพประจำปี
- [ ] ประสานงานกับ อปพร. และ สำนักงานป้องกันและบรรเทาสาธารณภัยจังหวัด
