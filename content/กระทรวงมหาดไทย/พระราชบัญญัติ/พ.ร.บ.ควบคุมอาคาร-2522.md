# พระราชบัญญัติควบคุมอาคาร พ.ศ. 2522

## สรุปสาระสำคัญ
**กฎหมายแม่** สำหรับการควบคุมการก่อสร้าง ดัดแปลง รื้อถอน เคลื่อนย้าย และการใช้อาคารทุกประเภทในประเทศไทย กำหนดมาตรฐานความปลอดภัยด้านโครงสร้าง อัคคีภัย และสุขอนามัย สำหรับอาคารที่ใช้เป็นที่อยู่อาศัย พาณิชยกรรม อุตสาหกรรม และบริการ

## ขอบเขตการบังคับใช้
| ประเภทอาคาร | ข้อกำหนด |
|------------|-----------|
| อาคารทั่วไป | ต้องขออนุญาตก่อสร้าง/ดัดแปลง |
| อาคารสูง (≥23 ม.) | มาตรฐานพิเศษตามกฎกระทรวง ฉ.55 |
| อาคารขนาดใหญ่พิเศษ | ระบบความปลอดภัยเพิ่มเติม |
| สถานบริการ | กฎกระทรวงเฉพาะ พ.ศ. 2555 |

- [[กฎกระทรวง-ควบคุมอาคาร-ฉ55-อาคารสูง-2543]] — มาตรฐานอาคารสูงและอาคารขนาดใหญ่พิเศษ
- [[กฎกระทรวง-ควบคุมอาคาร-สถานบริการ-2555]] — ระบบความปลอดภัยสถานบริการ
- [[กฎกระทรวง-ควบคุมอาคาร-ฉ67-2563]] — มาตรฐานทั่วไป (ปรับปรุงล่าสุด)

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าอาคารโรงงาน/คลังสินค้ามีใบอนุญาตก่อสร้างถูกต้อง
- [ ] อาคารที่ดัดแปลงใช้งานต้องขออนุญาตดัดแปลงอาคาร
- [ ] ตรวจสอบว่าอาคารเป็นไปตามกฎกระทรวงที่ออกตาม พ.ร.บ. นี้
- [ ] กรณีอาคารสูงหรืออาคารขนาดใหญ่พิเศษ — ตรวจสอบตามกฎกระทรวง ฉ.55
