# พระราชบัญญัติวัตถุระเบิด พ.ศ. 2530

## สรุปสาระสำคัญ
กำหนด **การควบคุมวัตถุระเบิด** ทุกประเภท ครอบคลุมการผลิต นำเข้า ส่งออก จำหน่าย เก็บ ขนย้าย และใช้วัตถุระเบิด โดยผู้ที่เกี่ยวข้องต้องได้รับ **ใบอนุญาต** จากอธิบดีกรมการปกครอง กำกับดูแลโดย **กรมการปกครอง กระทรวงมหาดไทย** ฝ่าฝืนมีโทษอาญาสูง

## ประเภทวัตถุระเบิดที่ควบคุม
| ประเภท | ตัวอย่าง |
|--------|---------|
| วัตถุระเบิดแรงสูง (High Explosive) | TNT, ANFO, Dynamite, PETN |
| วัตถุระเบิดดินดำ (Black Powder) | ดินปืน |
| ชนวนระเบิด (Detonator) | เชื้อปะทุ, ชนวน |
| พลุ / ดอกไม้เพลิง | ขนาดอุตสาหกรรม |
| วัตถุระเบิดประเภทอื่น | ตามที่กำหนดในกฎกระทรวง |

## กิจการที่ต้องขออนุญาต
| กิจกรรม | ผู้อนุญาต |
|---------|----------|
| ผลิตวัตถุระเบิด | อธิบดีกรมการปกครอง |
| นำเข้า/ส่งออก | อธิบดีกรมการปกครอง |
| จำหน่าย | อธิบดีกรมการปกครอง |
| เก็บวัตถุระเบิด | ผู้ว่าราชการจังหวัด |
| ขนย้ายวัตถุระเบิด | ผู้ว่าราชการจังหวัด / นายอำเภอ |
| ใช้วัตถุระเบิด (เหมือง/ก่อสร้าง) | ผู้ว่าราชการจังหวัด |

## อุตสาหกรรมที่เกี่ยวข้อง
- **เหมืองแร่** — ใช้วัตถุระเบิดในการระเบิดหิน
- **ก่อสร้างขนาดใหญ่** — ระเบิดหิน เปิดหน้าดิน อุโมงค์
- **อุตสาหกรรมดอกไม้เพลิง** — ผลิตและจำหน่าย
- **โรงงานผลิตวัตถุระเบิด** — ต้องมีใบอนุญาตพิเศษ

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่ากิจการเข้าข่ายต้องขออนุญาตวัตถุระเบิดหรือไม่
- [ ] ขอใบอนุญาตจากกรมการปกครองหรือผู้ว่าราชการจังหวัดก่อนดำเนินการ
- [ ] จัดทำบัญชีรับ-จ่ายวัตถุระเบิดและรายงานต่อเจ้าหน้าที่
- [ ] จัดเก็บวัตถุระเบิดในสถานที่เก็บที่ได้รับอนุญาตและได้มาตรฐาน
- [ ] ควบคุมการขนย้ายตามเส้นทางและเงื่อนไขที่ได้รับอนุญาต
- [ ] กำหนดผู้ควบคุมการใช้วัตถุระเบิดที่มีความรู้และใบอนุญาต
- [ ] ต่ออายุใบอนุญาตก่อนหมดอายุ
