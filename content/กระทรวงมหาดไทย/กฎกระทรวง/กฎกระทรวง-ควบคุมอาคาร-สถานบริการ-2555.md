# กฎกระทรวงกำหนดประเภทและระบบความปลอดภัยของอาคารที่ใช้เพื่อประกอบกิจการเป็นสถานบริการ พ.ศ. 2555

## สรุปสาระสำคัญ
กำหนด **ระบบความปลอดภัยเฉพาะสำหรับสถานบริการ** (ผับ บาร์ ไนท์คลับ คาราโอเกะ สถานบันเทิง) ออกหลังจากอุบัติเหตุอัคคีภัยร้ายแรงหลายครั้ง กำหนดมาตรฐานทางออกฉุกเฉิน ระบบดับเพลิง สัญญาณเตือนภัย และข้อกำหนดเฉพาะสำหรับสถานที่ที่มีคนรวมตัวหนาแน่น

## ขอบเขตการบังคับใช้
| ประเภทสถานบริการ | ต้องปฏิบัติตาม |
|-----------------|--------------|
| สถานบันเทิง (ผับ บาร์ ไนท์คลับ) | ✓ ทุกขนาด |
| คาราโอเกะ | ✓ ทุกขนาด |
| สถานประกอบการอาหาร (ขนาดใหญ่) | ✓ ตามที่กำหนด |
| สถานที่จัดงานประชุม/สัมมนา | ✓ ตามจำนวนผู้ใช้ |

## ข้อกำหนดสำคัญ
| ระบบ | ข้อกำหนด |
|------|-----------|
| ทางออกฉุกเฉิน | ต้องมีไม่น้อยกว่า 2 ทางออก |
| ป้ายทางออกฉุกเฉิน | ติดตั้งครบทุกทางออก — ต้องสว่างตลอดเวลา |
| ระบบ Sprinkler | บังคับ |
| สัญญาณเตือนอัคคีภัย | ต้องได้ยินทั่วอาคาร |
| ความจุสูงสุด | ต้องกำหนดและไม่เกิน |
| วัสดุตกแต่ง | ห้ามใช้วัสดุติดไฟง่าย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าสถานบริการมีทางออกฉุกเฉินอย่างน้อย 2 ทาง
- [ ] ตรวจสอบป้าย Exit ทุกป้ายให้สว่างตลอดเวลา
- [ ] ทดสอบระบบสัญญาณเตือนอัคคีภัยให้ได้ยินทั่วพื้นที่
- [ ] ตรวจสอบวัสดุตกแต่งภายในว่าไม่ใช่วัสดุติดไฟง่าย
- [ ] ควบคุมจำนวนผู้ใช้สถานบริการไม่ให้เกินความจุที่กำหนด
- [ ] ซ้อมอพยพหนีไฟตามกำหนด
