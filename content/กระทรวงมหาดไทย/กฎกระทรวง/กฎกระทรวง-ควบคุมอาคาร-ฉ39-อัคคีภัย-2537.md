# กฎกระทรวง ฉบับที่ 39 (พ.ศ. 2537) ออกตามความในพระราชบัญญัติควบคุมอาคาร พ.ศ. 2522

## สรุปสาระสำคัญ
กำหนด **ระบบความปลอดภัยด้านอัคคีภัย** สำหรับอาคารสูง อาคารขนาดใหญ่พิเศษ และอาคารที่มีคนใช้งานจำนวนมาก ครอบคลุมระบบป้องกันและดับเพลิง แสงสว่างฉุกเฉิน สัญญาณเตือนภัย และระบบระบายอากาศ รวมถึงแหล่งพลังงานสำรองกรณีฉุกเฉิน

## ระบบที่กำหนด
| ระบบ | ข้อกำหนด |
|------|-----------|
| ระบบดับเพลิงอัตโนมัติ (Sprinkler) | บังคับในอาคารสูงและขนาดใหญ่พิเศษ |
| สัญญาณเตือนอัคคีภัย | ต้องมีในอาคารทุกประเภทที่กำหนด |
| แสงสว่างฉุกเฉิน | ทุกทางออกและบันไดหนีไฟ |
| ระบบระบายอากาศฉุกเฉิน | ป้องกันควันในบันไดหนีไฟ |
| ไฟฟ้าสำรองฉุกเฉิน | Generator หรือ UPS สำหรับระบบฉุกเฉิน |
| ถังดับเพลิง | ทุก 1,000 ตร.ม. หรือตามที่กำหนด |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบและทดสอบระบบ Sprinkler ตามกำหนด
- [ ] ทดสอบสัญญาณเตือนอัคคีภัยประจำปี
- [ ] ตรวจสอบแบตเตอรี่ไฟฉุกเฉินตามระยะเวลาที่กำหนด
- [ ] บำรุงรักษาระบบระบายอากาศฉุกเฉิน (Smoke extraction)
- [ ] ตรวจสอบถังดับเพลิงและเติมสารดับเพลิงตามกำหนด
- [ ] ทดสอบ Generator ไฟฟ้าสำรองฉุกเฉินเป็นประจำ
