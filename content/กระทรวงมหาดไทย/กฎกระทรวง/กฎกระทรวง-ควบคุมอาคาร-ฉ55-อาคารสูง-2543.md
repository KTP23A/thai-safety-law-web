# กฎกระทรวง ฉบับที่ 55 (พ.ศ. 2543) ออกตามความในพระราชบัญญัติควบคุมอาคาร พ.ศ. 2522

## สรุปสาระสำคัญ
กำหนด **มาตรฐานความปลอดภัยสำหรับอาคารสูงและอาคารขนาดใหญ่พิเศษ** ครอบคลุมข้อกำหนดด้านโครงสร้าง ทางหนีไฟ ระบบป้องกันอัคคีภัย บันไดหนีไฟ ลิฟต์ดับเพลิง และระบบสาธารณูปโภคฉุกเฉิน กฎกระทรวงนี้เป็นมาตรฐานหลักสำหรับอาคารที่มีความสูงตั้งแต่ 23 เมตรขึ้นไป หรือมีพื้นที่อาคารรวมตั้งแต่ 10,000 ตร.ม. ขึ้นไป

## คำนิยาม (ประเภทอาคารที่บังคับใช้)
| ประเภท | คำนิยาม |
|--------|---------|
| อาคารสูง | อาคารที่มีความสูงตั้งแต่ 23.00 เมตรขึ้นไป |
| อาคารขนาดใหญ่พิเศษ | อาคารที่มีพื้นที่ใช้สอยรวมตั้งแต่ 10,000 ตร.ม. ขึ้นไป |

## ข้อกำหนดด้านความปลอดภัย
| ระบบ | ข้อกำหนด |
|------|-----------|
| บันไดหนีไฟ | ระยะห่างจากจุดไกลสุดในอาคารไม่เกิน 40 เมตร |
| ทางเดินหนีไฟ | ความกว้างขั้นต่ำตามจำนวนผู้ใช้อาคาร |
| ลิฟต์ดับเพลิง | บังคับสำหรับอาคารสูงเกิน 23 เมตร |
| วัสดุทนไฟ | โครงสร้างหลักต้องทนไฟไม่น้อยกว่า 3 ชั่วโมง |
| ระบบ Sprinkler | บังคับทุกชั้น |
| ถังน้ำสำรองดับเพลิง | ต้องมีความจุตามที่กำหนด |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าอาคารโรงงาน/คลังสินค้าที่สูง ≥23 เมตร เป็นไปตามกฎกระทรวงนี้
- [ ] ตรวจสอบบันไดหนีไฟ — ระยะทาง, ความกว้าง, ทิศทางเปิดประตู
- [ ] ตรวจสอบและทดสอบลิฟต์ดับเพลิง (Fire Lift) ประจำปี
- [ ] ตรวจสอบถังน้ำสำรองดับเพลิงให้มีน้ำเต็มตลอดเวลา
- [ ] ทดสอบระบบ Sprinkler และ Fire Alarm ครบทุกพื้นที่
- [ ] ตรวจสอบวัสดุทนไฟของโครงสร้างไม่ให้เสื่อมสภาพ
