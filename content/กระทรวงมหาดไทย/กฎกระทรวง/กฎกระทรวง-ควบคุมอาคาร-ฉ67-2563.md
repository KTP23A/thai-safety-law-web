# กฎกระทรวง ฉบับที่ 67 (พ.ศ. 2563) ออกตามความในพระราชบัญญัติควบคุมอาคาร พ.ศ. 2522

## สรุปสาระสำคัญ
กำหนด **มาตรฐานการก่อสร้างและดัดแปลงอาคาร** ฉบับปรับปรุงล่าสุด ครอบคลุมข้อกำหนดทั่วไปด้านลักษณะอาคาร ส่วนต่างๆ ของอาคาร ที่ว่างภายนอก แนวอาคาร ระยะต่างๆ และมาตรฐานความปลอดภัยที่อัปเดตให้ทันสมัย เป็นการแก้ไขเพิ่มเติมจากกฎกระทรวง ฉ.55 (พ.ศ. 2543)

## ข้อกำหนดที่ปรับปรุง
| หมวด | สาระสำคัญ |
|------|-----------|
| ลักษณะอาคาร | มาตรฐานโครงสร้างและวัสดุก่อสร้าง |
| ที่ว่างและระยะถอยร่น | กำหนดระยะจากแนวถนนและเขตที่ดิน |
| ทางหนีไฟ | ปรับปรุงข้อกำหนดความกว้างและระยะทาง |
| ที่จอดรถ | มาตรฐานโครงสร้างที่จอดรถ |
| ความสูงและจำนวนชั้น | ข้อกำหนดสำหรับประเภทอาคารต่างๆ |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าการก่อสร้างหรือดัดแปลงอาคารเป็นไปตามกฎกระทรวงฉบับนี้
- [ ] ตรวจสอบระยะถอยร่นอาคารจากถนนและเขตที่ดินข้างเคียง
- [ ] ตรวจสอบทางหนีไฟให้เป็นไปตามข้อกำหนดที่ปรับปรุง
- [ ] กรณีอาคารที่ก่อสร้างก่อน พ.ศ. 2563 — ตรวจสอบว่าต้องปรับปรุงหรือไม่
