# พระราชบัญญัติการสาธารณสุข พ.ศ. 2535

## สรุปสาระสำคัญ
**กฎหมายแม่** ด้านสาธารณสุขสำหรับสถานที่ประกอบกิจการและชุมชน กำหนดมาตรการเกี่ยวกับ การจัดการขยะมูลฝอย สิ่งปฏิกูล น้ำเสีย เหตุรำคาญ และสถานที่ที่อาจเป็นอันตรายต่อสุขภาพ บังคับใช้กับสถานประกอบกิจการทุกประเภท รวมถึงโรงงาน คลังสินค้า และสถานที่ทำงาน

## ขอบเขตการบังคับใช้
| หมวด | ข้อกำหนด |
|------|-----------|
| เหตุรำคาญ | ต้องไม่ก่อเหตุรำคาญแก่ชุมชนโดยรอบ |
| มูลฝอย | ต้องจัดการขยะตามที่กฎหมายกำหนด |
| สิ่งปฏิกูล | ระบบบำบัดน้ำเสียต้องได้มาตรฐาน |
| กิจการอันตรายต่อสุขภาพ | ต้องขออนุญาตก่อนเปิดกิจการ |

## โครงสร้างกฎหมายลูก (อนุบัญญัติสำคัญ)
- [[กฎกระทรวง-สถานประกอบกิจการอันตรายต่อสุขภาพ-2560]] — รายการกิจการที่เป็นอันตรายต่อสุขภาพ + ข้อกำหนด
- [[กฎกระทรวง-มูลฝอยอันตราย-2563]] — การจัดการมูลฝอยที่เป็นพิษหรืออันตรายจากชุมชน

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่ากิจการอยู่ในรายการ "กิจการที่เป็นอันตรายต่อสุขภาพ" หรือไม่ — หากใช่ ต้องขออนุญาต อปท.
- [ ] จัดการขยะมูลฝอยในโรงงาน/คลังสินค้าตามกฎหมาย ไม่เผากลางแจ้ง
- [ ] ระบบบำบัดน้ำเสียต้องได้มาตรฐานก่อนปล่อยทิ้ง
- [ ] ไม่ก่อเหตุรำคาญ (เสียงดัง กลิ่น ควัน) เกินมาตรฐานที่กำหนด
- [ ] จัดการมูลฝอยอันตราย (เคมี น้ำมัน สารพิษ) ตามกฎกระทรวงเฉพาะ
