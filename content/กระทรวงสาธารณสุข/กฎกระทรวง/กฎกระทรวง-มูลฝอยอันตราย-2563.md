# กฎกระทรวงการจัดการมูลฝอยที่เป็นพิษหรืออันตรายจากชุมชน พ.ศ. 2563

## สรุปสาระสำคัญ
กำหนด **หลักเกณฑ์และวิธีการจัดการมูลฝอยที่เป็นพิษหรืออันตราย** ที่เกิดขึ้นจากชุมชน ครอบคลุมการเก็บรวบรวม ขนส่ง และกำจัดขยะอันตราย เช่น หลอดไฟ แบตเตอรี่ บรรจุภัณฑ์สารเคมี น้ำมันเครื่องเสื่อมสภาพ ซึ่งพบในกระบวนการซ่อมบำรุงของโรงงานด้วย

## ประเภทมูลฝอยอันตรายที่ครอบคลุม
| ประเภท | ตัวอย่าง |
|--------|---------|
| มูลฝอยอิเล็กทรอนิกส์ | แบตเตอรี่ หลอดไฟ อุปกรณ์อิเล็กทรอนิกส์ |
| บรรจุภัณฑ์สารเคมี | กระป๋องสี บรรจุภัณฑ์ยาฆ่าแมลง |
| ของเสียน้ำมัน | น้ำมันเครื่องเก่า ผ้าเช็ดน้ำมัน |
| ยารักษาโรคหมดอายุ | ยาเม็ด ยาน้ำหมดอายุ |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] แยกมูลฝอยอันตรายออกจากขยะทั่วไปในโรงงาน
- [ ] จัดเก็บมูลฝอยอันตรายในภาชนะที่เหมาะสม ติดฉลากให้ชัดเจน
- [ ] ส่งมอบมูลฝอยอันตรายให้ อปท. หรือผู้รับใบอนุญาตจัดการ
- [ ] ไม่นำมูลฝอยอันตรายปนกับขยะทั่วไปหรือทิ้งในที่สาธารณะ
- [ ] บันทึกปริมาณมูลฝอยอันตรายที่ส่งกำจัด
