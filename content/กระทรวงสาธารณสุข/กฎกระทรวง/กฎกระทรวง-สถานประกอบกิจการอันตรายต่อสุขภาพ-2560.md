# กฎกระทรวงควบคุมสถานประกอบกิจการที่เป็นอันตรายต่อสุขภาพ พ.ศ. 2560

## สรุปสาระสำคัญ
กำหนด **รายการกิจการที่เป็นอันตรายต่อสุขภาพ** ที่ต้องขออนุญาตจากองค์กรปกครองส่วนท้องถิ่น (อปท.) ก่อนเปิดดำเนินการ รวมถึงข้อกำหนดด้านสุขลักษณะและมาตรการควบคุม ครอบคลุมกิจการอุตสาหกรรม การเกษตร และบริการที่อาจก่อให้เกิดอันตรายต่อสุขภาพชุมชน

## ตัวอย่างกิจการที่เป็นอันตรายต่อสุขภาพ (ที่เกี่ยวกับอุตสาหกรรม)
| ประเภทกิจการ | หมายเหตุ |
|------------|---------|
| กิจการเกี่ยวกับสัตว์หรือผลิตภัณฑ์จากสัตว์ | โรงฆ่าสัตว์ โรงเลี้ยงสัตว์ |
| กิจการเกี่ยวกับสารเคมี | การผสม บรรจุ เก็บรักษาสารเคมี |
| กิจการเกี่ยวกับโลหะ | หลอม ชุบ ทำความสะอาดโลหะ |
| กิจการที่ก่อให้เกิดฝุ่น เสียง กลิ่น | โรงงานบด ย่อย ตัด |
| กิจการเกี่ยวกับของเสีย | โรงงานคัดแยก กำจัดของเสีย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าธุรกิจอยู่ในรายการกิจการที่เป็นอันตรายต่อสุขภาพ
- [ ] หากอยู่ในรายการ — ต้องขอใบอนุญาตจาก อปท. ก่อนดำเนินการ
- [ ] ต่ออายุใบอนุญาตตามกำหนด (ปกติทุก 1 ปี)
- [ ] ปฏิบัติตามเงื่อนไขที่ อปท. กำหนดในใบอนุญาต
- [ ] กรณีกิจการที่มีเหตุรำคาญ ต้องดำเนินการแก้ไขตามคำสั่ง อปท.
