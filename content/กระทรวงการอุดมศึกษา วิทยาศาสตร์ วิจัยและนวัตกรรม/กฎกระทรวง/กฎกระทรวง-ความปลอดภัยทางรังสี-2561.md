# กฎกระทรวงความปลอดภัยทางรังสี พ.ศ. 2561

## สรุปสาระสำคัญ
กำหนด **มาตรฐานความปลอดภัยทางรังสี** สำหรับผู้ครอบครองหรือใช้วัสดุกัมมันตรังสีและเครื่องกำเนิดรังสี ครอบคลุมขีดจำกัดปริมาณรังสี (Dose Limit) พื้นที่ควบคุม การตรวจวัดรังสีบุคคล อุปกรณ์ป้องกันรังสี และข้อกำหนดสำหรับเจ้าหน้าที่ความปลอดภัยทางรังสี (RSO) สอดคล้องกับ IAEA Safety Standards

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| ขีดจำกัดปริมาณรังสี (Dose Limit) | ผู้ปฏิบัติงาน ≤ 20 mSv/ปี (เฉลี่ย 5 ปี), ไม่เกิน 50 mSv ในปีใดปีหนึ่ง |
| ประชาชนทั่วไป | ≤ 1 mSv/ปี |
| พื้นที่ควบคุม (Controlled Area) | กำหนดขอบเขต ติดป้ายเตือน จำกัดการเข้าออก |
| พื้นที่กำกับดูแล (Supervised Area) | ติดตามปริมาณรังสีสิ่งแวดล้อม |
| การตรวจวัดรังสีบุคคล | ผู้ปฏิบัติงานทางรังสีต้องสวม Dosimeter และส่งประเมินตามกำหนด |
| PPE รังสี | อุปกรณ์ป้องกันรังสีที่เหมาะสมต่อชนิดรังสี (แอลฟา เบตา แกมมา เอกซเรย์) |
| RSO | ต้องมีเจ้าหน้าที่ความปลอดภัยทางรังสีที่ผ่านการรับรอง OAP |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] กำหนดพื้นที่ควบคุมและพื้นที่กำกับดูแลทางรังสีให้ชัดเจน
- [ ] จัดให้ผู้ปฏิบัติงานทางรังสีสวม Dosimeter และรายงานปริมาณรังสีสะสม
- [ ] ติดป้ายเตือนสัญลักษณ์รังสี (Radiation Warning Symbol) ครบถ้วน
- [ ] จัดให้มีอุปกรณ์ป้องกันรังสีที่เหมาะสม (เสื้อกั้นรังสี แผ่นกั้น ฯลฯ)
- [ ] ตรวจสอบว่าปริมาณรังสีที่ได้รับไม่เกินขีดจำกัด Dose Limit ที่กำหนด
- [ ] จัดทำบันทึกปริมาณรังสีของผู้ปฏิบัติงานแต่ละคนอย่างเป็นระบบ
- [ ] มีแผนฉุกเฉินทางรังสีและซ้อมแผนเป็นประจำ
