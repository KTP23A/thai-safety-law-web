# กฎกระทรวงการอนุญาตเกี่ยวกับเครื่องกำเนิดรังสี พ.ศ. 2564

## สรุปสาระสำคัญ
กำหนด **หลักเกณฑ์ วิธีการ และเงื่อนไขในการขออนุญาตครอบครองหรือใช้เครื่องกำเนิดรังสี** ภายใต้ พ.ร.บ.พลังงานนิวเคลียร์เพื่อสันติ พ.ศ. 2559 ครอบคลุมเครื่องกำเนิดรังสีประเภทต่าง ๆ เช่น เครื่อง X-ray อุตสาหกรรม เครื่องฉายรังสีแกมมา อุปกรณ์ NDT และเครื่องกำเนิดรังสีทางการแพทย์ แบ่งประเภทใบอนุญาตตามความเสี่ยงของเครื่อง

## ประเภทเครื่องกำเนิดรังสีและข้อกำหนด
| ประเภท | ตัวอย่าง | ข้อกำหนด |
|--------|---------|-----------|
| ประเภทที่ 1 (ความเสี่ยงสูง) | เครื่อง X-ray อุตสาหกรรม NDT, เครื่องฉายรังสีแกมมา | ต้องขอใบอนุญาต OAP + มี RSO |
| ประเภทที่ 2 (ความเสี่ยงปานกลาง) | เครื่อง X-ray ทางการแพทย์ | ต้องขอใบอนุญาต OAP |
| ที่ได้รับยกเว้น | ตามที่ OAP กำหนด | แจ้งครอบครองตามมาตรา 26/2 |

## ข้อกำหนดสำหรับภาคอุตสาหกรรม (NDT/Radiography)
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| ใบอนุญาต | ต้องได้รับใบอนุญาตจาก OAP ก่อนใช้งาน |
| RSO | ต้องมีเจ้าหน้าที่ความปลอดภัยทางรังสีที่มีใบรับรอง OAP |
| พื้นที่ควบคุม | กำหนดขอบเขตพื้นที่ใช้งานเครื่อง ติดป้ายเตือน |
| การตรวจสอบ | ตรวจสอบสภาพเครื่องและมาตรการความปลอดภัยตามกำหนด |
| บันทึก | บันทึกการใช้งานและปริมาณรังสีของผู้ปฏิบัติงาน |
| ต่ออายุ | ต่ออายุใบอนุญาตก่อนหมดอายุตามระยะเวลาที่ OAP กำหนด |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าเครื่องกำเนิดรังสีทุกเครื่องในโรงงานมีใบอนุญาต OAP ที่ยังมีผลบังคับใช้
- [ ] ตรวจสอบใบอนุญาต RSO ของเจ้าหน้าที่ความปลอดภัยทางรังสียังไม่หมดอายุ
- [ ] กำหนดขอบเขตพื้นที่ควบคุมและติดป้ายเตือนรังสีให้ชัดเจน
- [ ] บันทึกการใช้งานเครื่องกำเนิดรังสีและปริมาณรังสีของผู้ปฏิบัติงานอย่างสม่ำเสมอ
- [ ] ไม่อนุญาตให้ผู้ที่ไม่ได้รับมอบหมายเข้าพื้นที่ควบคุมรังสี
- [ ] แจ้ง OAP ทันทีหากเครื่องกำเนิดรังสีสูญหาย ชำรุด หรือเกิดอุบัติเหตุทางรังสี
