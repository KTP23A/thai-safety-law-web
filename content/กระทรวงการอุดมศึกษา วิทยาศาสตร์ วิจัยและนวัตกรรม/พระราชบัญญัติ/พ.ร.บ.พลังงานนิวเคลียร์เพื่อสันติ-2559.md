# พระราชบัญญัติพลังงานนิวเคลียร์เพื่อสันติ พ.ศ. 2559

## สรุปสาระสำคัญ
**กฎหมายหลักด้านพลังงานนิวเคลียร์และรังสี** ของประเทศไทย กำหนดระบบการกำกับดูแลวัสดุนิวเคลียร์ วัสดุกัมมันตรังสี เครื่องกำเนิดรังสี และสถานประกอบการทางนิวเคลียร์ ครอบคลุมการขออนุญาต ความปลอดภัยทางรังสี การขนส่ง การจัดการกากกัมมันตรังสี และมาตรการป้องกันการแพร่ขยาย สำนักงานปรมาณูเพื่อสันติ (OAP) เป็นหน่วยงานกำกับดูแล

## ขอบเขตการบังคับใช้
| หมวด | ข้อกำหนด |
|------|-----------|
| วัสดุกัมมันตรังสี | ต้องขออนุญาต OAP ก่อนครอบครอง ใช้ นำเข้า/ส่งออก |
| เครื่องกำเนิดรังสี | เช่น เครื่อง X-ray อุตสาหกรรม ต้องได้รับใบอนุญาตหรือแจ้ง OAP |
| วัสดุนิวเคลียร์ | ต้องขออนุญาตและรายงาน Safeguards ต่อ IAEA |
| สถานประกอบการทางนิวเคลียร์ | ต้องผ่านการประเมินความปลอดภัยและรับใบอนุญาต |
| การขนส่ง | ต้องปฏิบัติตามกฎกระทรวงว่าด้วยการขนส่งวัสดุกัมมันตรังสี |
| กากกัมมันตรังสี | ต้องจัดการตามกฎกระทรวงที่ออกตามกฎหมายนี้ |
| เจ้าหน้าที่ความปลอดภัยทางรังสี (RSO) | ผู้ครอบครองต้องมี RSO ที่ได้รับใบอนุญาตจาก OAP |

## โครงสร้างกฎหมายลูก (สำคัญสำหรับภาคอุตสาหกรรม)
- [[กฎกระทรวง-ความปลอดภัยทางรังสี-2561]] — มาตรฐานความปลอดภัยทางรังสีทั่วไป
- [[กฎกระทรวง-เครื่องกำเนิดรังสี-2564]] — การอนุญาตเครื่องกำเนิดรังสี (X-ray อุตสาหกรรม)

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าโรงงานมีแหล่งกำเนิดรังสี (วัสดุกัมมันตรังสี/เครื่องกำเนิดรังสี) หรือไม่
- [ ] หากมี — ตรวจสอบว่ามีใบอนุญาต OAP หรือแจ้งครอบครองถูกต้องแล้ว
- [ ] ตรวจสอบว่ามีเจ้าหน้าที่ความปลอดภัยทางรังสี (RSO) ที่มีใบอนุญาต OAP ประจำ
- [ ] จัดทำแผนความปลอดภัยทางรังสีและแผนฉุกเฉินทางรังสี
- [ ] ตรวจสอบการจัดการกากกัมมันตรังสีให้ถูกต้องตามกฎกระทรวง
- [ ] ต่ออายุใบอนุญาตวัสดุกัมมันตรังสี/เครื่องกำเนิดรังสีก่อนหมดอายุ
