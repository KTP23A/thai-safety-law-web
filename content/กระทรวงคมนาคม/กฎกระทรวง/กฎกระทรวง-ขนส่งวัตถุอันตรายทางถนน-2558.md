# กฎกระทรวงความปลอดภัยในการขนส่งวัตถุอันตรายทางถนน พ.ศ. 2558

## สรุปสาระสำคัญ
กำหนด **มาตรฐานความปลอดภัยสำหรับการขนส่งวัตถุอันตรายทางถนน** ครอบคลุมข้อกำหนดเกี่ยวกับบรรจุภัณฑ์ ป้ายเตือน เอกสาร คุณสมบัติผู้ขับรถ อุปกรณ์ฉุกเฉิน และขั้นตอนการขนส่ง สอดคล้องกับมาตรฐาน UN/ADR สากล มีผลบังคับใช้ 30 วันหลังประกาศ (มีผล 8 ม.ค. 2559)

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| ป้าย Placard | ติดป้ายวัตถุอันตราย UN Class ทุกด้านรถ |
| บรรจุภัณฑ์ | ต้องเป็นมาตรฐาน UN ที่ได้รับการรับรอง |
| เอกสาร | ต้องพก Dangerous Goods Declaration ในรถ |
| ผู้ขับรถ | ต้องผ่านการอบรมและมีใบรับรองจาก กรมการขนส่งทางบก |
| อุปกรณ์ฉุกเฉิน | ถังดับเพลิง ชุด PPE อุปกรณ์ดูดซับ |
| เส้นทางและเวลา | บางพื้นที่กำหนดเส้นทางและเวลาขนส่ง |

## ประกาศลูก (ออกตามกฎกระทรวงนี้)
| ประกาศ | หัวข้อ |
|--------|--------|
| ประกาศกรมการขนส่งทางบก | บัญชีวัตถุอันตราย (UN Number/Class) |
| ประกาศกรมการขนส่งทางบก | อุปกรณ์ฉุกเฉินที่ต้องมีในรถ |
| ประกาศกรมการขนส่งทางบก | เอกสารประกอบการขนส่ง |
| ประกาศกรมการขนส่งทางบก | มาตรฐานการบรรทุกและยึดตรึง |
| ประกาศกรมการขนส่งทางบก | ข้อยกเว้นสำหรับปริมาณน้อย (พ.ศ. 2559) |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าบรรจุภัณฑ์วัตถุอันตรายเป็นมาตรฐาน UN
- [ ] ติดป้าย Placard ทุกด้านรถให้ถูกต้องตาม UN Class
- [ ] จัดทำ Dangerous Goods Declaration ก่อนขนส่งทุกครั้ง
- [ ] ตรวจสอบพนักงานขับรถมีใบรับรองการอบรมวัตถุอันตราย
- [ ] จัดให้มีอุปกรณ์ฉุกเฉินครบตามที่กำหนดในรถทุกคัน
- [ ] ซ้อมแผนฉุกเฉินกรณีอุบัติเหตุรถขนส่งวัตถุอันตราย
