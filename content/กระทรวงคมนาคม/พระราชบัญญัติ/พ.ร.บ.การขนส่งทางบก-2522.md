# พระราชบัญญัติการขนส่งทางบก พ.ศ. 2522

## สรุปสาระสำคัญ
**กฎหมายแม่** สำหรับการขนส่งทางบกทุกประเภทในประเทศไทย กำหนดการขออนุญาตประกอบกิจการขนส่ง มาตรฐานความปลอดภัยของรถและผู้ขับขี่ รวมถึงข้อกำหนดพิเศษสำหรับการขนส่งวัตถุอันตราย ซึ่งมีกฎกระทรวงลูกเฉพาะสำหรับวัตถุอันตราย

## ขอบเขตการบังคับใช้ (ด้านความปลอดภัย)
| ประเภท | ข้อกำหนด |
|--------|-----------|
| รถขนส่งวัตถุอันตราย | ต้องปฏิบัติตามกฎกระทรวงความปลอดภัยขนส่ง อ.ทันตราย 2558 |
| พนักงานขับรถวัตถุอันตราย | ต้องผ่านการอบรมและรับใบรับรอง |
| บรรจุภัณฑ์และป้ายเตือน | ต้องติดป้าย Placard ถูกต้องตาม UN class |
| เอกสารการขนส่ง | ต้องพกเอกสารประกอบการขนส่งวัตถุอันตราย |

## โครงสร้างกฎหมายลูก
- [[กฎกระทรวง-ขนส่งวัตถุอันตรายทางถนน-2558]] — ความปลอดภัยในการขนส่งวัตถุอันตราย

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่ารถขนส่งวัตถุอันตรายมีป้าย Placard ถูกต้องตาม UN class
- [ ] ตรวจสอบพนักงานขับรถวัตถุอันตราย — ต้องมีใบรับรองการอบรม
- [ ] จัดทำเอกสารการขนส่งวัตถุอันตราย (Dangerous Goods Declaration) ครบถ้วน
- [ ] ตรวจสอบสภาพรถและถังบรรจุก่อนขนส่งวัตถุอันตราย
