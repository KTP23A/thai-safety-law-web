# พระราชบัญญัติส่งเสริมและรักษาคุณภาพสิ่งแวดล้อมแห่งชาติ พ.ศ. 2535

## สรุปสาระสำคัญ
**กฎหมายแม่ด้านสิ่งแวดล้อม** ของประเทศไทย กำหนดระบบการประเมินผลกระทบสิ่งแวดล้อม (EIA/EHIA) มาตรฐานคุณภาพสิ่งแวดล้อม มาตรฐานควบคุมมลพิษจากแหล่งกำเนิด การกำหนดเขตควบคุมมลพิษ และกองทุนสิ่งแวดล้อม หน่วยงานหลัก ได้แก่ **กรมควบคุมมลพิษ (PCD)** กรมส่งเสริมคุณภาพสิ่งแวดล้อม และ สผ. (ONEP)

## ขอบเขตการบังคับใช้
| หมวด | ข้อกำหนด |
|------|-----------|
| EIA/EHIA | โครงการขนาดใหญ่หรืออาจกระทบสิ่งแวดล้อม ต้องจัดทำรายงาน EIA/EHIA |
| มาตรฐานน้ำทิ้ง | โรงงานอุตสาหกรรมต้องระบายน้ำทิ้งไม่เกินค่ามาตรฐานที่กระทรวงกำหนด |
| มาตรฐานอากาศเสีย | โรงงานต้องควบคุมการปล่อยอากาศเสียตามค่ามาตรฐาน |
| เขตควบคุมมลพิษ | พื้นที่ที่มีมลพิษสูงอาจถูกประกาศเป็น "เขตควบคุมมลพิษ" |
| ระบบบำบัดน้ำเสีย | โรงงานขนาดตามที่กำหนดต้องมีระบบบำบัดน้ำเสียและผู้ควบคุมที่ได้รับใบอนุญาต |
| กองทุนสิ่งแวดล้อม | สนับสนุนโครงการด้านสิ่งแวดล้อม |

## โครงสร้างกฎหมายลูก (สำคัญสำหรับอุตสาหกรรม)
- [[ประกาศกระทรวง-มาตรฐานน้ำทิ้งโรงงาน-2563]] — ค่ามาตรฐานน้ำทิ้งจากโรงงาน นิคม เขตอุตสาหกรรม
- [[ประกาศกระทรวง-มาตรฐานอากาศเสียโรงงาน-2563]] — ค่ามาตรฐานอากาศเสียจากโรงงานอุตสาหกรรม
- [[กฎกระทรวง-ผู้ควบคุมระบบบำบัดน้ำเสีย-2567]] — คุณสมบัติและใบอนุญาตผู้ควบคุมระบบบำบัดน้ำเสีย

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าโครงการขยายโรงงานต้องจัดทำ EIA หรือไม่
- [ ] ตรวจสอบค่าน้ำทิ้งให้อยู่ในมาตรฐานก่อนระบาย
- [ ] ตรวจสอบค่าอากาศเสีย (ฝุ่น SO₂ NOₓ ฯลฯ) ไม่เกินค่ามาตรฐาน
- [ ] มีระบบบำบัดน้ำเสียและผู้ควบคุมระบบที่ได้รับใบอนุญาต
- [ ] จัดทำรายงานผลการตรวจวัดมลพิษส่งหน่วยงานที่กำกับดูแลตามกำหนด

## ความสัมพันธ์กับกฎหมายอื่น
### เชื่อมโยงกับ

- [[พ.ร.บ.วัตถุอันตราย-2535]] — การจัดการกากของเสียอันตราย
