# ประกาศกระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม เรื่อง กำหนดมาตรฐานควบคุมการปล่อยทิ้งอากาศเสียจากโรงงานอุตสาหกรรม พ.ศ. 2563

## สรุปสาระสำคัญ
กำหนด **ค่ามาตรฐานสูงสุดของอากาศเสีย (Stack Emission)** ที่โรงงานอุตสาหกรรมสามารถปล่อยออกจากปล่องระบายสู่บรรยากาศ ครอบคลุมสารมลพิษหลัก ได้แก่ ฝุ่นละออง ก๊าซซัลเฟอร์ไดออกไซด์ (SO₂) ออกไซด์ของไนโตรเจน (NOₓ) และสารอินทรีย์ระเหยง่าย (VOCs) กำกับดูแลโดยกรมควบคุมมลพิษ ร่วมกับกรมโรงงานอุตสาหกรรม

## ค่ามาตรฐานอากาศเสียสำคัญ (ตัวอย่าง)
| มลพิษ | ค่ามาตรฐาน | หน่วย |
|------|-----------|------|
| ฝุ่นละออง (Particulate Matter) | ≤ 100 – 320 mg/m³ | ขึ้นอยู่กับประเภทโรงงาน |
| ซัลเฟอร์ไดออกไซด์ (SO₂) | ≤ 500 – 2,000 mg/m³ | ขึ้นอยู่กับเชื้อเพลิง |
| ออกไซด์ของไนโตรเจน (NOₓ) | ≤ 200 – 700 mg/m³ | ขึ้นอยู่กับประเภทอุตสาหกรรม |
| ไฮโดรเจนซัลไฟด์ (H₂S) | ≤ 10 mg/m³ | — |
| คลอรีน (Cl₂) | ≤ 30 mg/m³ | — |
| ไฮโดรเจนคลอไรด์ (HCl) | ≤ 100 mg/m³ | — |

*ค่าจริงขึ้นอยู่กับประเภทโรงงาน/กระบวนการผลิต — ดูรายละเอียดฉบับเต็ม*

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจวัดอากาศเสียจากปล่องโรงงานโดยห้องปฏิบัติการที่ได้รับการรับรอง
- [ ] ตรวจวัดอย่างน้อยปีละครั้ง หรือตามความถี่ที่หน่วยงานกำหนด
- [ ] บันทึกผลตรวจวัดและจัดเก็บเอกสารไว้ไม่น้อยกว่า 3 ปี
- [ ] รายงานผลการตรวจวัดต่อกรมโรงงานฯ / กรมควบคุมมลพิษตามกำหนด
- [ ] ดูแลอุปกรณ์ควบคุมมลพิษทางอากาศ (Scrubber, Bag Filter, ESP) ให้ทำงานได้ดี
- [ ] ตรวจสอบว่าค่าฝุ่น SO₂ NOₓ ไม่เกินมาตรฐานที่กำหนดสำหรับประเภทโรงงาน
