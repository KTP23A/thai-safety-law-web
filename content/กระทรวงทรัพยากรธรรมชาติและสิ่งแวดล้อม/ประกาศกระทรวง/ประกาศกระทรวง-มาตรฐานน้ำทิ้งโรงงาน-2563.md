# ประกาศกระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม เรื่อง กำหนดมาตรฐานควบคุมการระบายน้ำทิ้งจากโรงงานอุตสาหกรรม นิคมอุตสาหกรรม และเขตประกอบการอุตสาหกรรม พ.ศ. 2563

## สรุปสาระสำคัญ
กำหนด **ค่ามาตรฐานน้ำทิ้งสูงสุด** ที่อนุญาตให้โรงงานอุตสาหกรรม นิคมอุตสาหกรรม และเขตประกอบการอุตสาหกรรมระบายออกสู่แหล่งน้ำสาธารณะหรือระบบระบายน้ำสาธารณะ กำกับดูแลโดยกรมควบคุมมลพิษ ร่วมกับกรมโรงงานอุตสาหกรรม

## ค่ามาตรฐานน้ำทิ้งสำคัญ (ตัวอย่าง)
| พารามิเตอร์ | ค่ามาตรฐาน |
|-----------|-----------|
| pH | 5.5 – 9.0 |
| BOD (BOD₅) | ≤ 20 mg/L |
| COD | ≤ 120 mg/L |
| TSS (ของแข็งแขวนลอย) | ≤ 50 mg/L |
| TKN (ไนโตรเจนรวม) | ≤ 100 mg/L |
| น้ำมันและไขมัน | ≤ 5 mg/L |
| สารหนู (As) | ≤ 0.25 mg/L |
| ปรอท (Hg) | ≤ 0.005 mg/L |
| ตะกั่ว (Pb) | ≤ 0.2 mg/L |
| อุณหภูมิ | ≤ 40°C |

*ค่าจริงขึ้นอยู่กับประเภทโรงงานและแหล่งรับน้ำ — ดูรายละเอียดฉบับเต็ม*

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจวัดคุณภาพน้ำทิ้งก่อนระบายอย่างน้อยตามความถี่ที่กำหนด
- [ ] บันทึกผลตรวจวัดน้ำทิ้งและจัดเก็บตามกำหนด
- [ ] รายงานผลการตรวจวัดน้ำทิ้งต่อกรมโรงงานฯ / กรมควบคุมมลพิษตามกำหนด
- [ ] ดูแลระบบบำบัดน้ำเสียให้ทำงานได้อย่างมีประสิทธิภาพ
- [ ] ตรวจสอบว่าค่า pH, BOD, COD, TSS และโลหะหนักไม่เกินมาตรฐาน
- [ ] ติดตั้งมิเตอร์วัดปริมาณน้ำทิ้ง (กรณีโรงงานขนาดใหญ่)
