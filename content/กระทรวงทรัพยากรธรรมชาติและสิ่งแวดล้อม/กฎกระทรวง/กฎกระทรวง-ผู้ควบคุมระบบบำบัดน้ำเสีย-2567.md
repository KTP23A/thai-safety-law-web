# กฎกระทรวงการปฏิบัติงานเป็นผู้ควบคุมระบบบำบัดน้ำเสียและผู้รับจ้างให้บริการบำบัดน้ำเสีย พ.ศ. 2567

## สรุปสาระสำคัญ
กำหนด **คุณสมบัติ การขึ้นทะเบียน และหน้าที่** ของผู้ควบคุมระบบบำบัดน้ำเสีย (Wastewater Treatment Operator) และผู้รับจ้างให้บริการบำบัดน้ำเสีย สำหรับแหล่งกำเนิดมลพิษที่กฎหมายกำหนดให้ต้องมีระบบบำบัดน้ำเสีย ได้แก่ โรงงานอุตสาหกรรม นิคมอุตสาหกรรม และสถานประกอบกิจการขนาดตามที่กำหนด

## ข้อกำหนดสำคัญ
| หัวข้อ | ข้อกำหนด |
|--------|-----------|
| คุณสมบัติผู้ควบคุม | วุฒิการศึกษาด้านสิ่งแวดล้อม วิทยาศาสตร์ หรือวิศวกรรมที่เกี่ยวข้อง |
| การขึ้นทะเบียน | ขึ้นทะเบียนกับกรมควบคุมมลพิษ ก่อนปฏิบัติงาน |
| หน้าที่ผู้ควบคุม | ควบคุมดูแลระบบบำบัดน้ำเสียให้ทำงานถูกต้อง บันทึกผลการตรวจวัด |
| ผู้รับจ้างบำบัด | ต้องได้รับอนุญาตจากกรมควบคุมมลพิษ |
| การต่ออายุ | ต่ออายุใบอนุญาตตามระยะเวลาที่กรมฯ กำหนด |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าโรงงานต้องมีผู้ควบคุมระบบบำบัดน้ำเสียหรือไม่ (ตามขนาดและประเภท)
- [ ] หากต้องมี — ตรวจสอบว่าผู้ควบคุมขึ้นทะเบียนกับกรมควบคุมมลพิษแล้ว
- [ ] ตรวจสอบใบอนุญาตผู้ควบคุมระบบบำบัดน้ำเสียยังไม่หมดอายุ
- [ ] หากจ้างผู้รับจ้างภายนอก — ตรวจสอบว่าผู้รับจ้างมีใบอนุญาตถูกต้อง
