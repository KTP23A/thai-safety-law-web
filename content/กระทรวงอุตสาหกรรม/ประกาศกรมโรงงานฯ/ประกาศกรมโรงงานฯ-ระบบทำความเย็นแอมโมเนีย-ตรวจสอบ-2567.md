# ประกาศกรมโรงงานอุตสาหกรรม เรื่อง หลักเกณฑ์ วิธีการตรวจสอบและทดสอบความปลอดภัยของเครื่องจักรและอุปกรณ์ในระบบทำความเย็น และบุคลากรที่เกี่ยวข้อง พ.ศ. 2567

## สรุปสาระสำคัญ
กำหนด **หลักเกณฑ์และวิธีการตรวจสอบและทดสอบความปลอดภัย** สำหรับเครื่องจักรและอุปกรณ์ในระบบทำความเย็นที่ใช้แอมโมเนีย รวมถึงคุณสมบัติและหน้าที่ของบุคลากรที่เกี่ยวข้องกับการตรวจสอบ

## หลักเกณฑ์การตรวจสอบ
| รายการ | ข้อกำหนด |
|--------|-----------|
| ความถี่การตรวจสอบ | ตามที่ประกาศฯ กำหนด |
| ผู้ตรวจสอบ | วิศวกรที่ขึ้นทะเบียนกับกรมโรงงานฯ |
| รายงานการตรวจสอบ | ส่งกรมโรงงานฯ ภายในกำหนด |
| อุปกรณ์ที่ต้องตรวจ | คอมเพรสเซอร์, คอนเดนเซอร์, ท่อ, ลิ้นนิรภัย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จ้างวิศวกรที่ขึ้นทะเบียนถูกต้องมาตรวจสอบระบบทำความเย็น
- [ ] จัดทำรายงานการตรวจสอบตามแบบฟอร์มกรมโรงงานฯ
- [ ] ส่งรายงานภายในระยะเวลาที่กำหนด
- [ ] บำรุงรักษาและแก้ไขข้อบกพร่องตามที่วิศวกรระบุ
