# ประกาศกรมโรงงานฯ เรื่อง การรายงานข้อมูลโรงงานประจำปี (กรอ.1)

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์การรายงานข้อมูลโรงงานประจำปี **(กรอ.1)** ซึ่งโรงงานประเภทที่ 2 และ 3 ต้องยื่นผ่านระบบออนไลน์ **i-Industry Portal** ภายในวันที่ **31 มีนาคม** ของทุกปี

## ข้อมูลที่ต้องรายงานใน กรอ.1
| หมวด | รายการ |
|------|--------|
| ข้อมูลทั่วไป | ทุนจดทะเบียน จำนวนคนงาน กำลังผลิต |
| เครื่องจักร | ชนิด จำนวน กำลังแรงม้ารวม |
| วัตถุดิบ/สารเคมี | ชนิด ปริมาณที่ใช้ต่อปี |
| ของเสีย/กากอุตสาหกรรม | ชนิด ปริมาณ วิธีกำจัด |
| อุบัติเหตุ | จำนวนครั้ง ความรุนแรง |
| พลังงาน | ปริมาณการใช้ไฟฟ้า/น้ำมัน/ก๊าซ |

## กำหนดเวลาการยื่น
| โรงงาน | กำหนดส่ง |
|--------|---------|
| โรงงานประเภท 2 และ 3 | **ภายใน 31 มีนาคม** ของปีถัดไป |
| โรงงานที่หยุดกิจการ | แจ้งภายใน 30 วัน |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ลงทะเบียนระบบ **i-Industry Portal** หากยังไม่มีบัญชี
- [ ] รวบรวมข้อมูลเครื่องจักร, สารเคมี, และของเสีย **ตลอดปี** เพื่อกรอกรายงาน
- [ ] ยื่น กรอ.1 ก่อน **31 มีนาคม** ทุกปี (ปรับหากล่าช้า)
- [ ] เก็บสำเนาข้อมูลที่ส่งไว้ **อย่างน้อย 5 ปี**
