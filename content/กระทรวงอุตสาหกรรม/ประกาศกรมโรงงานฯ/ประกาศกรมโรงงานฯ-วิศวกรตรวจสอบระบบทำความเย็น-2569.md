# ประกาศกรมโรงงานอุตสาหกรรม เรื่อง หลักเกณฑ์และวิธีการขึ้นทะเบียนเป็นวิศวกรตรวจสอบระบบทำความเย็น และการจัดทำรายงานการตรวจสอบระบบทำความเย็น พ.ศ. 2569

## สรุปสาระสำคัญ
กำหนด **คุณสมบัติ หลักเกณฑ์ และวิธีการขึ้นทะเบียน** สำหรับวิศวกรที่ต้องการทำหน้าที่ตรวจสอบระบบทำความเย็น รวมถึงหลักเกณฑ์การจัดทำรายงานการตรวจสอบที่ถูกต้อง ประกาศนี้ออก **มีนาคม 2569** — ล่าสุด

## คุณสมบัติวิศวกรตรวจสอบ
| รายการ | ข้อกำหนด |
|--------|-----------|
| วุฒิการศึกษา | วิศวกรรมศาสตร์ (สาขาเกี่ยวข้อง) |
| ใบอนุญาตประกอบวิชาชีพ | ต้องมี ใบอนุญาตประกอบวิชาชีพวิศวกรรม (กว.) |
| การอบรม | ผ่านหลักสูตรที่กรมโรงงานฯ รับรอง |
| การขึ้นทะเบียน | ยื่นคำขอต่อกรมโรงงานอุตสาหกรรม |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าวิศวกรที่ใช้ตรวจสอบขึ้นทะเบียนถูกต้องตามประกาศนี้แล้ว
- [ ] หากโรงงานมีวิศวกรภายใน — ให้นำมาขึ้นทะเบียนกับกรมโรงงานฯ
- [ ] จัดทำรายงานการตรวจสอบตามแบบและหลักเกณฑ์ที่ประกาศกำหนด
- [ ] ต่ออายุการขึ้นทะเบียนตามวาระที่กำหนด
