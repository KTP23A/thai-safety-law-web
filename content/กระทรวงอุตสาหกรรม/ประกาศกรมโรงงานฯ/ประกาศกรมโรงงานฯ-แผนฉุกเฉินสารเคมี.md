# ประกาศกรมโรงงานฯ เรื่อง แผนฉุกเฉินสารเคมี (ERP)

## สรุปสาระสำคัญ
กำหนดหลักเกณฑ์การจัดทำ **แผนป้องกันและระงับอุบัติภัยจากสารเคมี (Emergency Response Plan — ERP)** สำหรับโรงงาน MHI รวมถึงการซักซ้อม การรายงาน และการประสานงานกับหน่วยงานภายนอก

## องค์ประกอบของ ERP
| หัวข้อ | รายการ |
|--------|--------|
| การแจ้งเตือน | สัญญาณเตือนภัย ระบบสื่อสาร รายชื่อผู้ติดต่อฉุกเฉิน |
| การอพยพ | เส้นทาง จุดรวมพล การนับจำนวนคน |
| การควบคุมเหตุ | ทีม ERT, อุปกรณ์ดับเพลิง/กักกันสาร |
| การประสานงานภายนอก | กรมโรงงาน, ดับเพลิง, โรงพยาบาล, ชุมชน |
| การฟื้นฟู | การทำความสะอาด การรายงานต่อราชการ |

## การซักซ้อมแผนฉุกเฉิน
| ประเภท | ความถี่ |
|--------|--------|
| Table-top Exercise | ปีละ 1 ครั้ง |
| Functional Exercise (ซักซ้อมจริง) | ทุก 2 ปี |
| Full-scale Drill | ทุก 3 ปี (รวมหน่วยงานภายนอก) |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดตั้ง **Emergency Response Team (ERT)** พร้อมฝึกอบรม
- [ ] จัดหา **ชุด PPE สารเคมี** (Level A/B/C) ให้เพียงพอ
- [ ] ซักซ้อมและบันทึก **After Action Report** ทุกครั้ง
- [ ] แจ้งกรมโรงงานฯ ภายใน **24 ชม.** เมื่อเกิดเหตุจริง
