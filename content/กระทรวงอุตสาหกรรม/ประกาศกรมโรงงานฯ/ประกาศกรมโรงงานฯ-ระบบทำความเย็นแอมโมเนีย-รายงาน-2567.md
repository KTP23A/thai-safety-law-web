# ประกาศกรมโรงงานอุตสาหกรรม เรื่อง หลักเกณฑ์และวิธีการ การจัดทำและส่งรายงานข้อมูลระบบทำความเย็นที่ใช้แอมโมเนีย พ.ศ. 2567

## สรุปสาระสำคัญ
กำหนด **หลักเกณฑ์และวิธีการ** สำหรับโรงงานที่มีระบบทำความเย็นที่ใช้แอมโมเนีย (NH₃) เป็นสารทำความเย็น ในการจัดทำและส่งรายงานข้อมูลเมื่อมีการ:
- **ติดตั้ง** ระบบทำความเย็นใหม่
- **ซ่อมแซมและดัดแปลง** ระบบที่มีอยู่
- **ยกเลิกการใช้งาน** ระบบทำความเย็น

## ขอบเขตการบังคับใช้
| กิจกรรม | ต้องรายงาน |
|---------|-----------|
| ติดตั้งระบบทำความเย็นแอมโมเนียใหม่ | ✓ ก่อนเริ่มใช้งาน |
| ซ่อมแซม/ดัดแปลงระบบ | ✓ ภายในกำหนด |
| ยกเลิกใช้งาน | ✓ แจ้งกรมโรงงานฯ |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] สำรวจและบันทึกข้อมูลระบบทำความเย็นแอมโมเนียที่มีในโรงงาน
- [ ] จัดทำรายงานข้อมูลตามแบบฟอร์มที่กรมโรงงานฯ กำหนด
- [ ] ส่งรายงานผ่านระบบอิเล็กทรอนิกส์ของกรมโรงงานฯ
- [ ] กำหนดผู้รับผิดชอบดูแลระบบรายงานอย่างต่อเนื่อง
