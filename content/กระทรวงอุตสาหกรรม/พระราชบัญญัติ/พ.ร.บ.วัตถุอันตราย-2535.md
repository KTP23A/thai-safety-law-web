# พระราชบัญญัติวัตถุอันตราย พ.ศ. 2535

## สรุปสาระสำคัญ
ควบคุมดูแลวัตถุอันตราย (สารเคมี, ยาฆ่าแมลง, สารกัดกร่อน, ก๊าซพิษ ฯลฯ) ตลอดวงจรชีวิต ตั้งแต่ **ผลิต นำเข้า ส่งออก มีไว้ครอบครอง ใช้ และกำจัด** ครอบคลุมหลายกระทรวง (อุตสาหกรรม, เกษตร, สาธารณสุข)

## ประเภทวัตถุอันตราย
| ชนิด | ลักษณะ | การควบคุม |
|------|--------|-----------|
| **ชนิดที่ 1** | อันตรายน้อย | แจ้งข้อเท็จจริง |
| **ชนิดที่ 2** | อันตรายปานกลาง | ขึ้นทะเบียน |
| **ชนิดที่ 3** | อันตรายสูง | **ต้องได้รับใบอนุญาต** |
| **ชนิดที่ 4** | อันตรายร้ายแรงมาก | **ห้ามผลิต นำเข้า ส่งออก มีไว้ครอบครอง** |

## หน่วยงานกำกับดูแล (แบ่งตามประเภทสาร)
| หน่วยงาน | ประเภทสาร |
|---------|-----------|
| **กรมโรงงานอุตสาหกรรม** | สารเคมีอุตสาหกรรม |
| **กรมวิชาการเกษตร** | สารกำจัดศัตรูพืช |
| **สำนักงาน อย.** | ยา เครื่องสำอาง |
| **กรมประมง** | สารใช้ในการประมง |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบประเภทวัตถุอันตรายก่อนสั่งซื้อ/นำเข้า
- [ ] ขึ้นทะเบียนวัตถุอันตรายชนิดที่ 2–3 **ก่อนนำเข้าหรือผลิต**
- [ ] จัดทำ **เอกสารข้อมูลความปลอดภัย (SDS)** ให้ครบ 16 หัวข้อ
- [ ] รายงานปริมาณการครอบครอง/ใช้ **ทุกปี** (สำหรับชนิดที่ 3)
- [ ] กำจัดวัตถุอันตรายที่ไม่ใช้งานตาม **กฎหมายกากอุตสาหกรรม**
