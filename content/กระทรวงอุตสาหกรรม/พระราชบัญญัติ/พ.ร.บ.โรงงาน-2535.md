# พระราชบัญญัติโรงงาน พ.ศ. 2535

## สรุปสาระสำคัญ
กฎหมายแม่บทของการควบคุมโรงงานอุตสาหกรรมในประเทศไทย กำหนดการจัดประเภทโรงงาน ระบบใบอนุญาต มาตรฐานความปลอดภัย สุขอนามัย และสิ่งแวดล้อม รวมถึงอำนาจของพนักงานเจ้าหน้าที่

## การจัดประเภทโรงงาน
| ประเภท | ลักษณะ | การควบคุม |
|--------|--------|-----------|
| **โรงงานประเภทที่ 1** | เครื่องจักร < 20 แรงม้า หรือคนงาน < 20 คน | แจ้งก่อนประกอบกิจการ |
| **โรงงานประเภทที่ 2** | เครื่องจักร 20–50 แรงม้า หรือคนงาน 20–50 คน | แจ้งก่อนประกอบกิจการ + ปฏิบัติตามมาตรฐาน |
| **โรงงานประเภทที่ 3** | เครื่องจักร > 50 แรงม้า หรือคนงาน > 50 คน | **ต้องได้รับใบอนุญาต** |

## หมวดความปลอดภัยที่สำคัญ
| มาตรา | เรื่อง |
|-------|--------|
| มาตรา 8 | นายจ้างต้องจัดให้มีมาตรการป้องกันอันตรายและสิ่งแวดล้อม |
| มาตรา 9 | กำหนดกฎกระทรวงว่าด้วยความปลอดภัย สุขลักษณะ และสวัสดิภาพ |
| มาตรา 34 | พนักงานเจ้าหน้าที่มีอำนาจเข้าตรวจโรงงาน |
| มาตรา 37 | สั่งปิดโรงงานชั่วคราวหากเป็นอันตรายร้ายแรง |
| มาตรา 45 | บทกำหนดโทษ — จำคุกไม่เกิน 2 ปี ปรับไม่เกิน 200,000 บาท |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดประเภทโรงงานให้ถูกต้อง (**ประเภท 3 ต้องมีใบอนุญาต**)
- [ ] ต่ออายุใบอนุญาตโรงงานทุก **5 ปี**
- [ ] แจ้งเปลี่ยนแปลงข้อมูลโรงงานภายใน **30 วัน**
- [ ] จัดทำรายงานข้อมูลโรงงาน (กรอ.1) ส่งกรมโรงงานฯ **ทุกปี**
