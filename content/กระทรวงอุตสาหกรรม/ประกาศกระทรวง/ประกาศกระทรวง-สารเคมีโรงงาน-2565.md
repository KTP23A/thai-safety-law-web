# ประกาศกระทรวงอุตสาหกรรม เรื่อง มาตรการความปลอดภัยเกี่ยวกับการจัดการสารเคมีในโรงงานอุตสาหกรรม พ.ศ. 2565

## สรุปสาระสำคัญ
กำหนด **มาตรการความปลอดภัยในการจัดการสารเคมี** ภายในโรงงานอุตสาหกรรม ครอบคลุม การจัดเก็บ การใช้ การขนย้าย การป้องกันอุบัติเหตุ และการจัดทำเอกสารข้อมูลความปลอดภัยของสารเคมี (SDS)

## ขอบเขตการบังคับใช้
| รายการ | ข้อกำหนด |
|--------|-----------|
| โรงงานที่ใช้สารเคมี | ต้องมีระบบจัดการสารเคมีตามประกาศฯ |
| SDS (Safety Data Sheet) | ต้องจัดทำและเผยแพร่ครบทุกสารเคมี |
| พื้นที่จัดเก็บ | ต้องมีมาตรการป้องกันการรั่วไหล |
| บุคลากร | ต้องผ่านการอบรมการจัดการสารเคมีอันตราย |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำทะเบียนสารเคมีทั้งหมดในโรงงาน (Chemical Inventory)
- [ ] จัดทำ SDS ให้ครบทุกสารเคมี และเผยแพร่ให้พนักงานเข้าถึงได้
- [ ] ติดป้าย GHS และ hazard label ที่ภาชนะบรรจุทุกชนิด
- [ ] ทบทวนขั้นตอนฉุกเฉินกรณีสารเคมีหก/รั่วไหล
