# กฎกระทรวง การเก็บวัตถุอันตรายในโรงงาน พ.ศ. 2551

## สรุปสาระสำคัญ
กำหนดมาตรฐานการเก็บรักษา **วัตถุอันตราย** ในโรงงาน ทั้งด้านกายภาพของคลังสินค้า การแบ่งแยกสารที่เข้ากันไม่ได้ ระบบป้องกัน และการจัดทำทะเบียนสารเคมี

## มาตรฐานคลังเก็บวัตถุอันตราย
| รายการ | ข้อกำหนด |
|--------|---------|
| โครงสร้างอาคาร | วัสดุทนไฟ FR-60 ขึ้นไป |
| ระบบระบายอากาศ | ≥ 10 รอบ/ชั่วโมง (สารระเหย) |
| พื้นคลัง | กันซึม ทนสารเคมี มีขอบกักสาร (bund wall) |
| ความสูงกองสินค้า | ไม่เกินที่กำหนดตามชนิดสาร |
| แสงสว่าง | ≥ 200 ลักซ์ |

## การแบ่งแยกสารเคมีที่เก็บร่วมกันไม่ได้
| กลุ่ม A | กลุ่ม B | ห้ามเก็บร่วม |
|--------|--------|------------|
| สารออกซิไดซ์ | สารไวไฟ | ✗ เด็ดขาด |
| กรด | ด่าง | ✗ เด็ดขาด |
| สารพิษ | อาหาร/ยา | ✗ เด็ดขาด |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำ **Chemical Inventory (ทะเบียนสารเคมี)** ให้ครบถ้วน
- [ ] ติด **ป้าย GHS** ที่ถูกต้องบนภาชนะทุกชิ้น
- [ ] มี **SDS** ครบทุกสารเคมีที่เก็บในคลัง
- [ ] ตรวจสอบคลังสารเคมีและบันทึกผล **ทุกเดือน**
- [ ] แจ้งกรมโรงงานฯ เมื่อปริมาณสารเกิน **Threshold Quantity**
