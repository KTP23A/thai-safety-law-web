# กฎกระทรวง ระบบไฟฟ้าในโรงงาน พ.ศ. 2550

## สรุปสาระสำคัญ
กำหนดมาตรฐานการออกแบบ ติดตั้ง บำรุงรักษา และตรวจสอบ **ระบบไฟฟ้าในโรงงาน** ให้ปลอดภัยตามมาตรฐาน วสท. (วิศวกรรมสถานแห่งประเทศไทย) หรือมาตรฐานสากล

## ข้อกำหนดหลัก
| รายการ | มาตรฐาน |
|--------|--------|
| การออกแบบระบบไฟฟ้า | วิศวกรไฟฟ้าเซ็นรับรอง |
| อุปกรณ์ป้องกัน (breaker, fuse) | มาตรฐาน มอก. / IEC |
| สายไฟและการเดินสาย | ตาม วสท. 2001-56 |
| ตู้ MDB / MCC | มีป้ายเตือน ล็อคได้ (LOTO) |
| การต่อลงดิน (Grounding) | ค่าความต้านทาน ≤ 5 โอห์ม |
| ห้องไฟฟ้า | ห้ามเก็บวัสดุไวไฟ |

## การตรวจสอบระบบไฟฟ้า
| ประเภท | ความถี่ | ผู้ตรวจ |
|--------|--------|--------|
| ตรวจสอบสายไฟ/ฉนวน | ทุกปี | วิศวกรไฟฟ้า |
| ทดสอบ Insulation Resistance | ทุกปี | วิศวกรไฟฟ้า |
| ตรวจสอบ Grounding | ทุก 2 ปี | วิศวกรไฟฟ้า |
| Thermoscan (Infrared) | ทุกปี | ผู้เชี่ยวชาญ |

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] จัดทำ **แผนผังระบบไฟฟ้า (Single Line Diagram)** ให้ทันสมัย
- [ ] ติดตั้งระบบ **LOTO (Lockout/Tagout)** ครบทุกจุด
- [ ] ให้วิศวกรไฟฟ้าตรวจสอบระบบ **ทุกปี** และบันทึกผล
- [ ] ห้ามต่อสายไฟชั่วคราวที่ไม่ได้มาตรฐาน
