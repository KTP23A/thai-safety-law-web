# กฎกระทรวง กำหนดประเภท ชนิด และขนาดของโรงงาน พ.ศ. 2563

## สรุปสาระสำคัญ
กำหนดรายการโรงงานอุตสาหกรรมทั้งหมดออกเป็น **156 ประเภท** แบ่งตามชนิดผลิตภัณฑ์และกระบวนการผลิต พร้อมระบุว่าแต่ละประเภทจัดอยู่ใน **โรงงานลำดับที่เท่าไหร่** (ประเภท 1/2/3)

## การจัดกลุ่มโรงงาน (ตัวอย่างหลัก)
| กลุ่ม | ตัวอย่างโรงงาน | ลำดับ |
|-------|--------------|-------|
| อาหาร | โรงสีข้าว, โรงงานน้ำตาล, โรงฆ่าสัตว์ | 1–3 |
| เคมี | โรงกลั่นน้ำมัน, ผลิตสารเคมี | 3 |
| โลหะ | หลอมโลหะ, ชุบโลหะ | 2–3 |
| อิเล็กทรอนิกส์ | ผลิต PCB, ประกอบเครื่องใช้ไฟฟ้า | 2–3 |
| พลาสติก/ยาง | รีดยาง, ฉีดพลาสติก | 2–3 |

## ความสำคัญของการจัดประเภท
- **ประเภท 1**: ประกอบกิจการได้เลย (แจ้งเท่านั้น)
- **ประเภท 2**: แจ้งก่อนเริ่ม + ปฏิบัติตามมาตรฐาน
- **ประเภท 3**: ต้องขอ **ใบอนุญาตประกอบกิจการโรงงาน (รง.4)** ก่อน

## ประเด็นสำคัญที่ต้องปฏิบัติ (Key Action Items)
- [ ] ตรวจสอบว่าโรงงานของตนเป็น **ลำดับที่เท่าไหร่**
- [ ] ประเภท 3 ต้องยื่นขอ **รง.4** ก่อนเริ่มประกอบกิจการ
- [ ] เมื่อขยายกำลังผลิตจนเปลี่ยนประเภท ต้อง **แจ้งกรมโรงงานฯ**
